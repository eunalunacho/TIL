### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181838)


### 문제 설명

정수 배열 date1과 date2가 주어집니다. 두 배열은 각각 날짜를 나타내며 [year, month, day] 꼴로 주어집니다. 각 배열에서 year는 연도를, month는 월을, day는 날짜를 나타냅니다.

만약 date1이 date2보다 앞서는 날짜라면 1을, 아니면 0을 return 하는 solution 함수를 완성해 주세요.



### 제한사항

- date1의 길이 = date2의 길이 = 3
- 0 ≤ year ≤ 10,000
- 1 ≤ month ≤ 12
- day는 month에 따라 가능한 날짜로 주어집니다.



### 입출력 예시

| date1 | date2 | result |
| --- | --- | --- |
| [2021, 12, 28] | [2021, 12, 29] | 1 |
| [1024, 10, 24] | [1024, 10, 24] | 0 |

- 첫 번째: date1이 하루 앞서므로 1
- 두 번째: 두 날짜가 같아서 date1이 더 앞서는 날짜가 아니므로 0



### 내 풀이

```python
def solution(date1, date2):
    if date1[0] != date2[0]:
        return 1 if date1[0] < date2[0] else 0
    if date1[1] != date2[1]:
        return 1 if date1[1] < date2[1] else 0
    return 1 if date1[2] < date2[2] else 0
```


### 코드 설명

연도 → 월 → 일 순서로 보면서, **처음으로 다른 칸에서 결과를 결정**한다. 앞 칸이 같을 때만 다음 칸으로 넘어간다.

- 연도가 다르면 월과 일은 볼 필요 없이 연도만으로 결정
- 연도가 같고 월이 다르면 월로 결정
- 연도와 월이 같으면 일로 결정. 일까지 같으면 `date1 < date2`가 거짓이라 0

**처음에 틀린 코드**

```python
def solution(date1, date2):
    if date1[0] < date2[0]:
        return 1
    elif date1[1] < date2[1]:
        return 1
    elif date1[2] < date2[2]:
        return 1
    return 0
```

- "각 칸에서 date1이 더 작은 게 하나라도 있으면 1"이라고 생각했는데, 이러면 틀린다
- 반례: `[2022, 1, 5]`와 `[2021, 3, 9]`. 연도는 2022 > 2021이라 넘어가지만, 월에서 `1 < 3`이 참이라 1이 나온다. 정답은 0 (date1이 연도에서 이미 더 늦다)
- **월은 연도가 같을 때만, 일은 연도와 월이 같을 때만 비교해야 한다.** 앞 칸에서 이미 정해진 결과를 뒤 칸이 뒤집으면 안 된다
- 랜덤 입력 10만 쌍으로 재 보니 이 틀린 코드가 약 35%에서 다른 결과를 냈다



### 다른 풀이

```python
def solution(date1, date2):
    return int(date1 < date2)
```

- **리스트는 앞에서부터 차례로 비교한다.** 첫 칸이 다르면 거기서 결정되고, 같을 때만 다음 칸을 본다. 위의 풀이가 직접 쓴 규칙과 정확히 같다
- 비교 결과는 `True` / `False`인데, `int()`로 바꾸면 `1` / `0`이 된다. 문제가 정수를 반환하라고 했으니 `int()`로 감싸는 게 안전하다
- `[2021, 12, 28] < [2021, 12, 29]`는 앞 두 칸이 같고 마지막에서 28 < 29이므로 `True`

삼항 연산자로 써도 같다.

```python
def solution(date1, date2):
    return 1 if date1 < date2 else 0
```

`datetime.date`로 비교하는 방법은 이 문제에서는 쓸 수 없다.

```python
from datetime import date

def solution(date1, date2):
    return int(date(*date1) < date(*date2))
```

- 날짜끼리는 `<`로 바로 비교되고 `date(*date1)`로 리스트를 풀어서 넘길 수 있지만, 이 문제는 연도 범위가 **0 이상 10,000 이하**다
- `datetime.date`의 연도는 **1~9999만 허용**해서 `date(0, 1, 1)`은 `ValueError`가 난다
- 풀이 3개 모두 랜덤 입력 10만 쌍에서 내 풀이와 결과가 같은지 확인함 (연도 1~12 범위에서)



### 기록

- **여러 칸을 순서대로 비교(연도 → 월 → 일)할 때는 앞 칸이 같을 때만 다음 칸을 본다.** 각 칸을 따로따로 비교하면 틀린다
- **리스트와 튜플은 앞에서부터 사전순으로 비교된다.** `[2021, 12, 28] < [2021, 12, 29]`처럼 바로 쓸 수 있다
- 같은 원리: [배열 비교하기]에서 `(길이, 합)` 튜플로 비교한 것과 같다. **우선순위가 있는 기준은 순서대로 나열한 튜플/리스트로 비교**
- `True`는 1, `False`는 0이라서 `int(조건)`으로 1 / 0을 만들 수 있다
- 라이브러리(`datetime`)는 편하지만 입력 범위가 허용 범위를 벗어나면 에러가 난다. 제한사항의 범위와 비교해 보고 쓰기
- 반례를 직접 만들어 보는 습관: 앞 칸은 크고 뒤 칸은 작은 입력처럼, 코드의 가정이 깨지는 경우를 찾는다
