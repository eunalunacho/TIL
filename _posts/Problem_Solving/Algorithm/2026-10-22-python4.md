### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181879)


### 문제 설명

정수가 담긴 리스트 num_list가 주어질 때, 리스트의 길이가 11 이상이면 리스트에 있는 모든 원소의 합을 10 이하이면 모든 원소의 곱을 return하도록 solution 함수를 완성해주세요.



### 제한사항

- 2 ≤ num_list의 길이 ≤ 20
- 1 ≤ num_list의 원소 ≤ 9
- num_list의 원소를 모두 곱했을 때 2,147,483,647를 넘는 입력은 주어지지 않습니다.



### 입출력 예시

| num_list | result | 
| --- | --- |  
| [3, 4, 5, 2, 5, 4, 6, 7, 3, 7, 2, 2, 1] | 51 |
| [2, 3, 4, 5] | 120 |



### 내 풀이

```python
def solution(num_list):
    if len(num_list) >= 11:
        return sum(num for num in num_list)
    else:
        mul = 1
        for num in num_list:
            mul = mul * num
        return mul
```


### 코드 설명

합은 sum()으로 바로 구했는데, 곱도 `from math import prod`로 한 번에 구할 수 있다는 걸 떠올리지 못해서 반복문으로 직접 곱했다.

곱을 직접 구할 때는 0이 아니라 1에서 시작해야 함. 0에서 시작하면 무엇을 곱해도 0이 됨



### 다른 풀이

```python
from math import prod

def solution(num_list):
    return sum(num_list) if len(num_list) >= 11 else prod(num_list)
```

- `sum(num for num in num_list)`는 원소를 하나씩 꺼내서 그대로 다시 넘기는 것이라 `sum(num_list)`와 같음 → 리스트를 바로 넘기면 됨
- `math.prod()`는 sum()의 곱셈 버전. 리스트의 모든 원소를 곱해줌 (파이썬 3.8 이상)
- 조건이 두 갈래뿐이라 `A if 조건 else B` 한 줄로 쓸 수 있음
- 시간복잡도는 둘 다 O(n)으로 같지만, 직접 반복문을 짜지 않고 내장 함수에 맡기면 코드가 짧고 실수할 여지가 줄어듦



### 기록

- 합은 `sum()`, 곱은 `math.prod()`. 곱을 직접 구할 때는 시작값을 1로
- 제한사항의 "2,147,483,647을 넘지 않는다"는 C++, Java의 int 범위(32비트) 때문에 붙은 조건. 파이썬 정수는 크기 제한이 없어서 신경 쓰지 않아도 됨
