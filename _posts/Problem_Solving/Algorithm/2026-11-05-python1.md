### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181857)


### 문제 설명

정수 배열 arr이 매개변수로 주어집니다. arr의 길이가 2의 정수 거듭제곱이 되도록 arr 뒤에 정수 0을 추가하려고 합니다. arr에 최소한의 개수로 0을 추가한 배열을 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 1 ≤ arr의 길이 ≤ 1,000
- 1 ≤ arr의 원소 ≤ 1,000



### 입출력 예시

| arr | result |
| --- | --- |
| [1, 2, 3, 4, 5, 6] | [1, 2, 3, 4, 5, 6, 0, 0] |
| [58, 172, 746, 89] | [58, 172, 746, 89] |



### 내 풀이

```python
def solution(arr):
    lth = 1
    while lth < len(arr):
        lth = lth * 2

    return arr + [0] * (lth - len(arr))
```


### 코드 설명

1부터 시작해서 2배씩 키우다가, arr의 길이 이상이 되는 첫 값이 "채워야 할 목표 길이"다. 모자란 만큼 0을 뒤에 붙인다.

- 목표 길이는 **arr 길이 이상인 가장 작은 2의 거듭제곱**. 가장 작은 걸 골라야 0이 최소로 들어간다
- 길이가 이미 2의 거듭제곱이면 `lth == len(arr)`에서 멈추고, `[0] * 0`은 빈 리스트라 그대로 반환된다
- 길이가 1일 때도 `lth = 1`에서 바로 멈춘다
- 시간: 반복은 log₂(1000) ≈ 10번 안쪽이라 사실상 O(n) (리스트 합치기)



### 다른 풀이

```python
def solution(arr):
    size = 1 << (len(arr) - 1).bit_length()
    return arr + [0] * (size - len(arr))
```

2진수로 보면 `bit_length()`로 한 번에 구할 수 있다. 2의 거듭제곱은 2진수로 쓰면 **1이 하나뿐**이다(`1`, `10`, `100`, `1000`...).

| 길이 n | n-1 | (n-1)의 2진수 | bit_length | 1 << bit_length |
| --- | --- | --- | --- | --- |
| 6 | 5 | `101` | 3 | 8 |
| 4 | 3 | `11` | 2 | 4 |
| 1 | 0 | `0` | 0 | 1 |

- `n - 1`을 쓰는 이유: `n`이 이미 2의 거듭제곱이면 `n.bit_length()`는 한 단계 커진다(4는 `100`이라 3자리 → 8). `n - 1`로 빼면 이 경우도 같이 맞는다
- `1 << k`는 `2 ** k`와 같다
- 시간: 반복문 없이 O(1)로 크기를 구한다. 이 문제에선 while 풀이와 속도 차이를 느낄 수준은 아니다

2진수 판별로도 풀 수 있다. `n & (n - 1)`은 n이 2의 거듭제곱일 때만 0이다.

```python
def solution(arr):
    while len(arr) & (len(arr) - 1):
        arr.append(0)
    return arr
```

- 예: 8(`1000`) & 7(`0111`) = 0, 6(`110`) & 5(`101`) = `100` ≠ 0
- 0을 하나씩 붙이면서 "2의 거듭제곱인가?"를 매번 확인하는 방식. 원본 `arr`을 직접 바꾸는 점은 주의

`math.log2`로 푸는 방법도 있지만 float 연산이라 오차가 생길 수 있어서 정수만 쓰는 위 방법들이 더 안전하다.

```python
import math

def solution(arr):
    size = 2 ** math.ceil(math.log2(len(arr)))
    return arr + [0] * (size - len(arr))
```



### 기록

- **2의 거듭제곱 = 2진수로 1이 하나뿐인 수.** `n & (n - 1) == 0`이면 2의 거듭제곱
- n 이상인 가장 작은 2의 거듭제곱: `1 << (n - 1).bit_length()`. `n - 1`을 쓰는 이유는 n 자체가 2의 거듭제곱인 경우 때문
- 2진수 변환: `bin(13)` → `'0b1101'`, `bin(13)[2:]` → `'1101'`, `format(13, 'b')` → `'1101'`
- 손으로 바꿀 땐 2로 계속 나눠서 **나머지를 아래에서 위로** 읽는다
- 모자란 만큼 채우기: `리스트 + [값] * (목표 길이 - len(리스트))`. 모자라지 않으면 `[값] * 0`이라 그대로 반환
- 경계값(길이 1, 이미 2의 거듭제곱인 길이)을 먼저 확인하기
