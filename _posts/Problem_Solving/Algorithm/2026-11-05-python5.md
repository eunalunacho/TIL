### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181853)


### 문제 설명

정수로 이루어진 리스트 num_list가 주어집니다. num_list에서 가장 작은 5개의 수를 오름차순으로 담은 리스트를 return하도록 solution 함수를 완성해주세요.



### 제한사항

- 6 ≤ num_list의 길이 ≤ 30
- 1 ≤ num_list의 원소 ≤ 100



### 입출력 예시

| num_list | result |
| --- | --- |
| [12, 4, 15, 46, 38, 1, 14] | [1, 4, 12, 14, 15] |

[12, 4, 15, 46, 38, 1, 14]를 정렬하면 [1, 4, 12, 14, 15, 38, 46]이 되고, 앞에서부터 5개를 고르면 [1, 4, 12, 14, 15]가 된다.



### 내 풀이

```python
def solution(num_list):
    num_list.sort()
    return num_list[:5]
```


### 코드 설명

오름차순으로 정렬한 뒤 앞에서 5개를 잘라서 반환한다.

- `sort()`: 리스트를 **제자리에서** 오름차순으로 정렬한다. 반환값은 `None`이다
- `[:5]`: 처음부터 5번째까지(인덱스 0~4) 자르는 슬라이싱. 길이가 5보다 짧아도 에러가 없지만, 이 문제는 길이가 6 이상이라 항상 5개가 나온다
- 주의: `sort()`는 **받은 리스트 자체를 바꾼다.** 이 문제에서는 상관없지만, 원본이 필요한 상황에서는 문제가 될 수 있다
- 시간: 정렬이 O(n log n). 길이 30 이하라 충분하다



### 다른 풀이

```python
def solution(num_list):
    return sorted(num_list)[:5]
```

- `sorted()`는 **원본을 그대로 두고 정렬된 새 리스트**를 만든다. 한 줄로 끝나고, 호출한 쪽의 리스트가 바뀌지 않는다
- 헷갈리기 쉬운 점: `num_list.sort()[:5]`처럼 쓰면 `sort()`가 `None`을 반환해서 `None[:5]`가 되어 에러가 난다. 한 줄로 쓰려면 `sorted()`를 쓴다

작은 값 n개만 필요할 때 쓰는 함수도 있다.

```python
import heapq

def solution(num_list):
    return heapq.nsmallest(5, num_list)
```

- `heapq.nsmallest(n, 리스트)`는 가장 작은 n개를 **오름차순으로** 반환한다. "작은 것 n개"라는 의도가 이름에 드러난다
- 전체를 정렬하지 않고 필요한 개수만 골라서, 리스트가 아주 길고 n이 작을 때 `sorted()[:n]`보다 유리하다
- 이 문제는 길이가 30 이하라 속도 차이는 의미가 없다. 가독성 때문에 선택하는 정도
- 반대로 큰 값 n개는 `heapq.nlargest(n, 리스트)`
- 세 풀이 모두 랜덤 입력 5만 번으로 결과가 같은지 확인함



### 기록

- **`sort()`와 `sorted()`의 차이**
  - `a.sort()`: 원본을 바꾸고 `None`을 반환
  - `sorted(a)`: 원본은 그대로, 정렬된 새 리스트를 반환
- 원본을 바꾸지 않으면서 한 줄로 쓰려면 `sorted()`. `a.sort()[:5]`는 `None`을 자르려는 것이라 에러
- 작은 값 n개: `sorted(a)[:n]` 또는 `heapq.nsmallest(n, a)`, 큰 값 n개: `sorted(a)[-n:]`(오름차순) 또는 `heapq.nlargest(n, a)`(내림차순)
- 슬라이싱 `[:5]`는 범위를 넘어가도 에러가 나지 않고 있는 만큼만 돌려준다 (인덱싱 `[5]`는 에러)
- 문제 제목("뒤에서 5등")은 순위 기준이 헷갈릴 수 있다. 설명의 "가장 작은 5개 오름차순"이 실제 요구사항
