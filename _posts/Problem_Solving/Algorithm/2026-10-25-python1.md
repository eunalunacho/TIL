### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181867)


### 문제 설명

문자열 myString이 주어집니다. myString을 문자 "x"를 기준으로 나눴을 때 나눠진 문자열 각각의 길이를 순서대로 저장한 배열을 return 하는 solution 함수를 완성해 주세요.



### 제한사항

- 1 ≤ myString의 길이 ≤ 100,000
- myString은 알파벳 소문자로 이루어진 문자열입니다.



### 입출력 예시

| myString | result |
| --- | --- |
| "oxooxoxxox" | [1, 2, 1, 0, 1, 0] |
| "xabcxdefxghi" | [0, 3, 3, 3] |



### 내 풀이

```python
def solution(myString):
    return [len(string) for string in (myString.split("x"))]
```


### 코드 설명

`split("x")`로 "x" 기준으로 나눈 뒤, 나눠진 문자열마다 `len()`으로 길이를 구해서 리스트에 담음

```python
"oxooxoxxox".split("x")   # ['o', 'oo', 'o', '', 'o', '']
```

- "x"가 연달아 있거나(`xx`) 맨 앞·맨 뒤에 있으면 빈 문자열 `''`이 생기고, 길이 0으로 세야 함
- 그래서 이 문제는 구분자를 꼭 지정해야 함. 구분자를 지정하면 빈 문자열도 그대로 남음
- `myString.split("x")`를 감싼 괄호는 없어도 됨



### 다른 풀이

```python
def solution(myString):
    return list(map(len, myString.split("x")))
```

- `map(함수, 리스트)`: 리스트의 원소마다 함수를 적용함. `len`을 괄호 없이 함수 자체로 넘김
- `map`은 결과를 바로 리스트로 주지 않아서 `list()`로 감쌈
- 길이 100,000짜리 입력으로 직접 재 보니 내 풀이보다 약 12% 빨랐음. 이미 있는 함수(`len`)를 원소마다 적용만 할 때는 `map`이 컴프리헨션보다 조금 빠름
- 차이가 크지 않아서 읽기 편한 쪽을 써도 됨



### 기록

- `split("구분자")`는 구분자가 연속되거나 앞뒤에 있으면 빈 문자열을 남김. 빈 문자열도 세야 하는 문제에 맞음
- 원소마다 기존 함수 하나만 적용할 때는 `list(map(함수, 리스트))`도 가능
