### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/42579)


### 문제 설명

스트리밍 사이트에서 장르 별로 가장 많이 재생된 노래를 두 개씩 모아 베스트 앨범을 출시하려 합니다. 노래는 고유 번호로 구분하며, 노래를 수록하는 기준은 다음과 같습니다.

1. 속한 노래가 많이 재생된 장르를 먼저 수록합니다.
2. 장르 내에서 많이 재생된 노래를 먼저 수록합니다.
3. 장르 내에서 재생 횟수가 같은 노래 중에서는 고유 번호가 낮은 노래를 먼저 수록합니다.

노래의 장르를 나타내는 문자열 배열 genres와 노래별 재생 횟수를 나타내는 정수 배열 plays가 주어질 때, 베스트 앨범에 들어갈 노래의 고유 번호를 순서대로 return 하도록 solution 함수를 완성하세요.



### 제한사항

- genres[i]는 고유번호가 i인 노래의 장르입니다.
- plays[i]는 고유번호가 i인 노래가 재생된 횟수입니다.
- genres와 plays의 길이는 같으며, 이는 1 이상 10,000 이하입니다.
- 장르 종류는 100개 미만입니다.
- 장르에 속한 곡이 하나라면, 하나의 곡만 선택합니다.
- 모든 장르는 재생된 횟수가 다릅니다.



### 입출력 예시

| genres | plays | return |
| --- | --- | --- |
| ["classic", "pop", "classic", "classic", "pop"] | [500, 600, 150, 800, 2500] | [4, 1, 3, 0] |



### 내 풀이

```python
from collections import Counter, defaultdict
def solution(genres, plays):
    answer = []

    total = Counter()
    for n, s in zip(genres, plays):
        total[n] += s

    ttl = list(total)
    ttl.sort(key=lambda x: -total[x])

    srt = defaultdict(list)
    for i, gen in enumerate(genres):
        srt[gen].append((plays[i], i))

    for gen in ttl:
        tmp = srt[gen]
        tmp = sorted(tmp, key=lambda x: (-x[0], x[1]))
        cnt = 0
        for i in range(len(tmp)):
            answer += [tmp[i][1]]
            cnt += 1
            if cnt == 2:
                break

    return answer
```


### 코드 설명

수록 기준이 두 단계라서 정보를 두 묶음으로 나눴다.

| 기준 | 필요한 정보 |
| --- | --- |
| 많이 재생된 **장르** 먼저 | ① 장르 → 총 재생수 (`total`) |
| 장르 **안에서** 많이 재생된 노래 먼저, 같으면 번호 낮은 것 | ② 장르 → (재생수, 고유번호) 목록 (`srt`) |

1. ①을 총 재생수가 큰 순으로 정렬해 장르 순서를 정한다
2. 그 순서대로 ②의 노래 목록을 **재생수 큰 순, 같으면 번호 작은 순**으로 정렬한다
3. 앞에서 최대 2개의 번호를 답에 넣는다

- 시간: 정렬 → **O(n log n)**

막혔던 곳이 많았다.

- **값을 더하는 방법**: `Counter(리스트)`는 등장 횟수만 세고 재생수를 더해 주지 않는다. 반복문에서 `total[n] += s`로 하나씩 더해야 한다
- **`list(total).sort()`가 None**: `sort()`는 원본을 바꾸고 None을 반환한다. 또 `list(total)`은 장르 **이름** 리스트라서 그냥 정렬하면 알파벳순이 된다. 예시에서 `pop`이 `classic`보다 먼저 나온 건 우연이었다
- **`ttl[x]`로 총합을 꺼내려다 에러**: `ttl`은 이름 리스트라 총합이 없다. 총합은 `total`에 있으니 `total[x]`
- **`for i, gen in genres`**: 인덱스를 같이 받으려면 `enumerate(genres)`
- **`Counter`에 리스트를 `+=`**: Counter는 없는 키가 숫자 0이라 `0 + 리스트`가 에러. 목록을 모을 땐 `defaultdict(list)` + `append`
- **`sorted(tmp, ...)`만 써서 정렬이 안 됨**: `sorted()`는 새 리스트를 반환할 뿐 `tmp`를 바꾸지 않는다. `tmp = sorted(...)`로 받아야 한다
- **절반이 런타임 에러**: `for i in range(2)`로 썼더니 곡이 1개인 장르에서 `tmp[1]`이 없어 `IndexError`. 문제 조건 "장르에 속한 곡이 하나라면"이 예시에는 없는 경우였다



### 다른 풀이

```python
from collections import defaultdict

def solution(genres, plays):
    total = defaultdict(int)
    songs = defaultdict(list)
    for i, (g, p) in enumerate(zip(genres, plays)):
        total[g] += p
        songs[g].append((p, i))

    answer = []
    for g in sorted(total, key=lambda x: -total[x]):
        top = sorted(songs[g], key=lambda x: (-x[0], x[1]))[:2]
        answer += [i for p, i in top]
    return answer
```

- **반복문 두 개를 하나로**: `enumerate(zip(...))`로 번호, 장르, 재생수를 한 번에 받는다. `enumerate`가 `(번호, (장르, 재생수))` 모양으로 주니까 `i, (g, p)`처럼 괄호로 받는다
- **`sorted(딕셔너리)`**: 키를 정렬한 리스트를 바로 준다. `list()` 후 `sort()`할 필요 없음
- **`cnt` + `break` 대신 `[:2]`**: 슬라이싱은 길이를 넘어도 에러 없이 있는 만큼만 준다
- **`[i for p, i in top]`**: 튜플에서 번호만 뽑는다. `answer += 리스트`는 `answer.extend(리스트)`와 같다
- 시간은 내 풀이와 같다. 짧아지고 실수할 곳이 줄었다



### 기록

**도구**

- `zip(a, b)`: 같은 위치끼리 짝지어 하나씩 꺼낸다. 길이가 다르면 짧은 쪽에 맞춰 멈춘다
- 인덱스까지 필요하면 `for i, (g, p) in enumerate(zip(a, b))`
- `defaultdict(기본값 형태)`: 없는 키를 부르면 기본값을 자동으로 만든다. `list`면 `[]`(목록 모으기), `int`면 `0`(숫자 더하기). `Counter`도 기본값 0
- 값을 더할 땐 `Counter(리스트)`가 아니라 반복문에서 `+=`

**정렬**

- `sort()`는 원본을 바꾸고 None, `sorted()`는 새 리스트를 반환. `sorted()`는 결과를 꼭 받아야 한다
- `sorted()`에 무엇을 넣어도 리스트로 준다. 딕셔너리를 넣으면 **키만** 정렬한 리스트
- 기준은 `key=`. 기준이 여러 개면 `key=lambda x: (기준1, 기준2)`. 튜플은 첫 값부터 비교하고 같으면 다음 값
- `lambda x`의 `x`에는 정렬하는 리스트의 **요소가 하나씩** 들어간다. 비교할 값은 다른 곳(`total[x]`)에서 꺼내도 된다
- `reverse=True`는 모든 기준을 한꺼번에 뒤집는다. 방향이 섞이면 숫자에 `-`를 붙인다: `(-재생수, 번호)`
- 리스트 안 튜플의 요소: `lst[2][1]`처럼 대괄호 두 번

**습관**

- "최대 k개"는 `[:k]`. 리스트가 k보다 짧아도 에러가 안 난다
- 런타임 에러가 나면 **예시에 없는 경우**부터 의심하기: 1개뿐, 0개, 최솟값·최댓값
- 기준이 두 단계인 문제의 틀: ① 그룹별 합계 + ② 그룹별 목록을 **한 반복문에서** 만들고, 그룹 순서대로 꺼내 정렬
