### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181870)


### 문제 설명

문자열 배열 strArr가 주어집니다. 배열 내의 문자열 중 "ad"라는 부분 문자열을 포함하고 있는 모든 문자열을 제거하고 남은 문자열을 순서를 유지하여 배열로 return 하는 solution 함수를 완성해 주세요.



### 제한사항

- 1 ≤ strArr의 길이 ≤ 1,000
- 1 ≤ strArr의 원소의 길이 ≤ 20
- strArr의 원소는 알파벳 소문자로 이루어진 문자열입니다.



### 입출력 예시

| strArr | result |
| --- | --- |
| ["and","notad","abcd"] | ["and","abcd"] |
| ["there","are","no","a","ds"] | ["there","are","no","a","ds"] |



### 내 풀이

```python
def solution(strArr):
    answer = []
    for st in strArr:
        if "ad" not in st:
            answer.append(st)
    return answer
```


### 코드 설명

`"ad" in st`로 문자열 안에 "ad"가 들어 있는지 확인하고, 없는 것만 새 리스트에 담았다.

처음에는 원본 리스트를 돌면서 `remove()`로 지우는 방식으로 풀었는데 실패했다.

```python
def solution(strArr):
    for st in strArr:
        if "ad" in st:
            strArr.remove(st)
    return strArr
```

for문은 내부적으로 "지금 몇 번 인덱스를 보는지"를 기억하면서 0, 1, 2 순서로 넘어간다. 그런데 도는 중에 원소를 지우면 뒤 원소들이 한 칸씩 앞으로 당겨져서, 바로 다음 원소를 건너뛰게 된다.

```
strArr = ["bad", "mad", "cat"]

i=0: "bad" → "ad" 있음 → remove → ["mad", "cat"]
i=1: "cat" → "ad" 없음        ← "mad"가 0번으로 당겨져서 검사를 건너뜀
결과: ["mad", "cat"]  (정답은 ["cat"])
```

"ad"가 들어간 문자열이 연달아 있을 때만 틀려서 예시는 통과하고 일부 테스트에서 실패했다.

또 하나 헷갈린 점: `remove()`는 같은 값이 여러 개 있어도 **처음 나온 하나만** 지운다.

```python
a = [1, 2, 3, 2, 2]
a.remove(2)   # [1, 3, 2, 2]
```



### 다른 풀이

```python
def solution(strArr):
    return [st for st in strArr if "ad" not in st]
```

- 내 풀이를 리스트 컴프리헨션으로 한 줄로 줄인 것. 조건만 남기는 필터라서 `if`를 for 뒤에 씀

처음에 `[st if "ad" not in st for st in strArr]`로 썼다가 else가 없다는 에러가 났다. if 위치에 따라 문법이 다르다.

```python
a = ["and", "notad", "abcd"]
[s for s in a if "ad" not in s]           # ['and', 'abcd']       ← for 뒤 if: 필터, 원소를 뺌
[s if "ad" not in s else "X" for s in a]  # ['and', 'X', 'abcd']  ← for 앞 if: 조건 표현식, 원소를 바꿈
```

- for 앞자리는 "담을 값"을 쓰는 곳 → 조건이 False일 때 담을 값도 있어야 해서 else 필수
- for 뒤의 if는 "담을지 말지"만 정함 → False면 안 담으면 그만이라 else를 쓸 수 없음

- 원본을 건드리지 않고 새 리스트를 만들어서 위의 건너뛰기 문제가 생기지 않음
- 길이 1000짜리 입력으로 직접 재 보니 내 풀이보다 약 20% 빨랐음 (`append()` 메서드를 매번 찾아 호출하는 비용이 없음)



### 기록

- **반복 중인 리스트에서 원소를 지우지 않는다.** 지우면 다음 원소를 건너뜀 → 남길 것만 새 리스트에 담기
- `remove(값)`은 처음 나온 하나만 지움. 같은 값을 전부 지우려면 `[x for x in a if x != 값]`
- 리스트에는 `drop`이 없음 (pandas 메서드). 리스트는 `remove(값)`, `pop(인덱스)`, `del a[i]`
- 부분 문자열 포함 여부는 `in` / `not in`
- 컴프리헨션에서 원소를 **빼려면** for 뒤에 `if`(else 없음), **바꾸려면** for 앞에 `if ... else ...`(else 필수)
