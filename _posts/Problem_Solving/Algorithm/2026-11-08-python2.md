### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181839)


### 문제 설명

1부터 6까지 숫자가 적힌 주사위가 두 개 있습니다. 두 주사위를 굴렸을 때 나온 숫자를 각각 a, b라고 했을 때 얻는 점수는 다음과 같습니다.

- a와 b가 모두 홀수라면 a² + b² 점을 얻습니다.
- a와 b 중 하나만 홀수라면 2 × (a + b) 점을 얻습니다.
- a와 b 모두 홀수가 아니라면 |a - b| 점을 얻습니다.

두 정수 a와 b가 매개변수로 주어질 때, 얻는 점수를 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- a와 b는 1 이상 6 이하의 정수입니다.



### 입출력 예시

| a | b | result |
| --- | --- | --- |
| 3 | 5 | 34 |
| 6 | 1 | 14 |
| 2 | 4 | 2 |

- 첫 번째: 둘 다 홀수라서 3² + 5² = 9 + 25 = 34
- 두 번째: 하나만 홀수라서 2 × (6 + 1) = 14
- 세 번째: 둘 다 홀수가 아니라서 |2 - 4| = 2



### 내 풀이

```python
def solution(a, b):
    if a%2 and b%2:
        return a*a + b*b
    elif not (a%2) and not (b%2):
        return abs(a-b)
    else:
        return 2 * (a + b)
```


### 코드 설명

홀수·짝수 조합 세 가지를 `if`, `elif`, `else`로 나눴다.

- `a%2`는 홀수면 1, 짝수면 0이다. 파이썬은 `1`을 참, `0`을 거짓으로 보기 때문에 `if a%2 and b%2`는 "둘 다 홀수"라는 뜻이 된다
- `not (a%2) and not (b%2)`는 "둘 다 짝수"다
- 둘 다 홀수도 둘 다 짝수도 아니면 **남은 경우는 하나만 홀수인 경우뿐**이라서, 세 번째 조건을 따로 쓰지 않고 `else`로 처리했다
- `abs(a-b)`: 절댓값. 둘 중 어느 쪽이 큰지 몰라도 차이를 양수로 구해 준다
- 시간: 조건 몇 개만 확인하므로 O(1)



### 다른 풀이

로직은 이미 간결하다. 조건을 다르게 보는 방법을 정리했다.

**1. 홀수 개수로 나누기**

```python
def solution(a, b):
    odd = a % 2 + b % 2
    if odd == 2:
        return a * a + b * b
    if odd == 1:
        return 2 * (a + b)
    return abs(a - b)
```

- `a % 2 + b % 2`는 **홀수인 주사위의 개수(0, 1, 2)**다. 문제의 세 경우가 "홀수가 몇 개인가"로 정확히 나뉘어서 조건 하나(`odd`)로 정리된다
- 문제 설명 순서(2개 → 1개 → 0개)와 코드의 순서가 같아서 읽기 쉽다
- 조건이 `odd == 2`처럼 숫자로 드러나서 `not (a%2)` 같은 부정이 없다

**2. 조건을 `or`로 이어서 `elif` 없애기**

```python
def solution(a, b):
    if a % 2 and b % 2:
        return a * a + b * b
    if a % 2 or b % 2:
        return 2 * (a + b)
    return abs(a - b)
```

- 첫 `if`에서 "둘 다 홀수"를 먼저 걸러내면 두 번째에 오는 `a % 2 or b % 2`는 **"둘 다 홀수는 아닌데 적어도 하나는 홀수 = 하나만 홀수"**가 된다
- 위에서 걸러진 경우는 아래 조건에서 다시 볼 필요가 없다는 점을 이용한다. `return`으로 끝나니 `elif`와 `else`도 필요 없다
- 마지막 `return abs(a - b)`는 "홀수가 하나도 없는" 경우만 남는다

**3. 인덱싱으로 고르기 (재미로만)**

```python
def solution(a, b):
    return (abs(a - b), 2 * (a + b), a * a + b * b)[a % 2 + b % 2]
```

- 홀수 개수(0, 1, 2)를 **튜플의 인덱스**로 써서 해당 점수를 꺼낸다
- 짧지만 세 점수를 매번 다 계산하고, 어떤 인덱스가 어떤 경우인지 알아보기 어렵다. 1번 형태가 더 낫다
- 세 풀이 모두 가능한 모든 경우(6 × 6 = 36개)에서 내 풀이와 결과가 같은지 확인함



### 기록

- **`n % 2`는 홀수면 1, 짝수면 0.** 조건식에서 그대로 참/거짓으로 쓸 수 있다
- **여러 대상의 홀짝 조합은 `a % 2 + b % 2`(홀수 개수)로 세면 갈래가 깔끔해진다**
- `return`으로 끝나는 `if`는 `elif`/`else` 없이 이어 써도 된다. 위에서 걸러진 경우는 아래에서 다시 따지지 않아도 된다
- `not (a%2)`보다 `a%2 == 0`이 읽기 쉽다. 부정은 가능하면 피하기
- 절댓값은 `abs()`. 두 수의 차이(거리)는 `abs(a - b)`
- 제곱은 `a*a` 또는 `a**2`. 문제 설명의 `a2`는 a²이다 (옮겨 적을 때 위 첨자가 사라지니 주의)
