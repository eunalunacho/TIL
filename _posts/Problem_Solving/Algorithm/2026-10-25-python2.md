### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181866)


### 문제 설명

문자열 myString이 주어집니다. "x"를 기준으로 해당 문자열을 잘라내 배열을 만든 후 사전순으로 정렬한 배열을 return 하는 solution 함수를 완성해 주세요.

단, 빈 문자열은 반환할 배열에 넣지 않습니다.



### 제한사항

- 1 ≤ myString ≤ 100,000
- myString은 알파벳 소문자로 이루어진 문자열입니다.



### 입출력 예시

| myString | result |
| --- | --- |
| "axbxcxdx" | ["a","b","c","d"] |
| "dxccxbbbxaaaa" | ["aaaa","bbb","cc","d"] |



### 내 풀이

```python
def solution(myString):
    tmp = myString.split('x')
    tmp.sort()
    return [string for string in tmp if string != '']
```


### 코드 설명

`split('x')`로 자르고, `sort()`로 사전순 정렬한 뒤, 컴프리헨션으로 빈 문자열을 뺐다.

풀면서 두 번 막혔다.

1) 빈 문자열을 `remove('')`로 지우려다 `builtin_function_or_method object has no attribute remove` 에러가 났다. `split` 뒤에 괄호를 빠뜨려서 리스트가 아니라 **함수 자체**에 `.remove`를 붙였기 때문이다.

```python
s.split.remove('')     # split 함수 자체에 remove → 에러
s.split().remove('')   # 괄호가 있어야 리스트
```

괄호를 고쳐도 `remove()`는 처음 나온 빈 문자열 하나만 지워서 이 문제에는 맞지 않는다.

2) 결과가 `None`으로 나왔다. `sort()`, `remove()`, `append()`처럼 **리스트를 그 자리에서 바꾸는 메서드는 `None`을 돌려준다.** 그래서 `return tmp.sort()`처럼 쓰면 None이 반환된다.

```python
tmp.sort()            # 원본을 정렬, 반환값 None
return tmp

return sorted(tmp)    # 정렬된 새 리스트를 반환
```

`print()`는 화면에 보여 주기만 하고, 채점은 `return` 값으로 한다. return이 없는 함수의 결과도 None이다.



### 다른 풀이

```python
def solution(myString):
    return sorted(filter(None, myString.split('x')))
```

- `filter(None, 리스트)`: False로 취급되는 값(`''`, `0`, `None` 등)을 걸러 줌. 빈 문자열만 빠짐
- `sorted()`는 정렬된 **새 리스트**를 돌려줘서 바로 return할 수 있음
- 빈 문자열을 먼저 빼고 정렬해서 정렬할 원소 수가 줄어듦
- 길이 100,000짜리 입력으로 직접 재 보니 내 풀이보다 약 2~9% 빨랐음. 속도 차이는 거의 없고, 한 줄로 끝나는 게 장점

컴프리헨션으로 쓰면 `sorted(s for s in myString.split('x') if s)`. 빈 문자열은 조건문에서 False라서 `if s != ''` 대신 `if s`로 줄일 수 있다.



### 기록

- **리스트를 그 자리에서 바꾸는 메서드(`sort`, `remove`, `append`, `extend`)는 `None`을 반환**. 정렬 결과를 바로 쓰려면 `sorted()`
- `builtin_function_or_method object has no attribute ...` 에러는 메서드 뒤에 `()`를 빠뜨렸다는 뜻
- 빈 문자열 전부 빼기: `[s for s in a if s]` 또는 `list(filter(None, a))`
- `''`, `0`, `[]`, `None`은 조건문에서 False
