### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181862)


### 문제 설명

임의의 문자열이 주어졌을 때 문자 "a", "b", "c"를 구분자로 사용해 문자열을 나누고자 합니다.

예를 들어 주어진 문자열이 "baconlettucetomato"라면 나눠진 문자열 목록은 ["onlettu", "etom", "to"] 가 됩니다.

문자열 myStr이 주어졌을 때 위 예시와 같이 "a", "b", "c"를 사용해 나눠진 문자열을 순서대로 저장한 배열을 return 하는 solution 함수를 완성해 주세요.

단, 두 구분자 사이에 다른 문자가 없을 경우에는 아무것도 저장하지 않으며, return할 배열이 빈 배열이라면 ["EMPTY"]를 return 합니다.



### 제한사항

- 1 ≤ myStr의 길이 ≤ 1,000,000
- myStr은 알파벳 소문자로 이루어진 문자열 입니다.



### 입출력 예시

| myStr | result |
| --- | --- |
| "baconlettucetomato" | ["onlettu", "etom", "to"] |
| "abcd" | ["d"] |
| "cabab" | ["EMPTY"] |



### 내 풀이

```python
import re
def solution(myStr):
    answer = list(filter(None, re.split('[abc]', myStr)))
    if len(answer) == 0:
        return ["EMPTY"]
    else:
        return answer
```


### 코드 설명

문자열의 `split()`에는 구분자를 하나만 넣을 수 있다. `split('abc')`는 "a나 b나 c"가 아니라 "abc"라는 덩어리를 구분자로 본다.

그래서 정규표현식 `re.split()`을 썼다.

- `[abc]`: "a, b, c 중 아무 글자 하나"
- 구분자가 연달아 있거나 맨 앞·뒤에 있으면 빈 문자열 `''`이 생김 → `filter(None, ...)`로 걸러냄
- 남은 게 없으면 `["EMPTY"]`



### 다른 풀이

```python
def solution(myStr):
    return myStr.replace('a', ' ').replace('b', ' ').replace('c', ' ').split() or ["EMPTY"]
```

- a, b, c를 전부 공백으로 바꾼 뒤 인자 없는 `split()`으로 자름
- 인자 없는 `split()`은 연속 공백을 하나로 보고 앞뒤 공백도 무시해서, **빈 문자열이 아예 생기지 않음** → filter가 필요 없음
- `A or B`: A가 비어 있으면(False) B를 돌려줌. 빈 리스트 `[]`는 False라서 결과가 없으면 `["EMPTY"]`가 됨. if/else를 한 줄로 줄인 것
- 길이 1,000,000짜리 입력으로 직접 재 보니 내 풀이보다 2~4.7배 빨랐음. 정규표현식은 범용이라 느리고, `replace()`와 `split()`은 단순 작업을 C에서 바로 처리함

바꿀 글자가 많으면 `translate()`로 한 번에 바꿀 수 있다.

```python
def solution(myStr):
    return myStr.translate(str.maketrans('abc', '   ')).split() or ["EMPTY"]
```

- `str.maketrans('abc', '   ')`: a→공백, b→공백, c→공백 변환표를 만듦 (두 문자열 길이가 같아야 함)
- `translate()`는 문자열을 한 번만 훑으면서 변환표대로 바꿈. replace를 세 번 하면 세 번 훑음
- 직접 재 보니 내 풀이보다 3~8배 빨라서 가장 빨랐음

정규표현식을 쓴다면 자르는 대신 남길 것을 찾는 방법도 있다.

```python
import re
def solution(myStr):
    return re.findall('[^abc]+', myStr) or ["EMPTY"]
```

- `[^abc]+`: a, b, c가 **아닌** 글자가 1개 이상 이어진 덩어리. `^`가 대괄호 안 맨 앞에 오면 "제외"라는 뜻
- 남길 덩어리만 찾아서 빈 문자열이 생기지 않음
- 내 풀이보다 1.2~2.8배 빨랐지만 replace, translate 풀이보다는 느렸음



### 기록

- `str.split()`은 구분자 하나만. 여러 개로 자르려면 `re.split('[abc]', s)`, 또는 구분자를 하나로 통일(`replace`/`translate`)한 뒤 split
- 공백으로 통일하고 인자 없는 `split()`을 쓰면 빈 문자열 처리까지 한 번에 됨
- `결과 or 기본값`: 결과가 비어 있으면 기본값. 빈 리스트·빈 문자열·0은 False
- 정규표현식 `[abc]`는 a/b/c 중 하나, `[^abc]`는 a/b/c를 제외한 글자, `+`는 1개 이상
- 입력이 크면(10^6) 정규표현식보다 문자열 메서드가 빠름
