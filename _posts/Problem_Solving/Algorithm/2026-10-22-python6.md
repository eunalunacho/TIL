### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181874)


### 문제 설명

문자열 myString이 주어집니다. myString에서 알파벳 "a"가 등장하면 전부 "A"로 변환하고, "A"가 아닌 모든 대문자 알파벳은 소문자 알파벳으로 변환하여 return 하는 solution 함수를 완성하세요.



### 제한사항

- 1 ≤ myString의 길이 ≤ 20
- myString은 알파벳으로 이루어진 문자열입니다.



### 입출력 예시

| myString | result | 
| --- | --- |  
| "abstract algebra" | "AbstrAct AlgebrA" |
| "PrOgRaMmErS" | "progrAmmers" |



### 내 풀이

```python
def solution(myString):
    st = []
    for char in myString:
        if char == "a":
            st.append(char.upper())
        elif char == "A":
            st.append(char)
        else:
            st.append(char.lower())
    return "".join(st)
```


### 코드 설명

처음엔 `"".append(...)`로 문자열에 바로 덧붙이려다 에러가 났다. `append()`는 리스트 전용이고, 문자열은 한 번 만들면 내용을 바꿀 수 없어서(immutable) 덧붙이는 메서드가 없음.
문자열 여러 개를 하나로 합칠 때는 `"".join()`을 씀

```python
"".join(["a", "b", "c"])    # "abc"
"-".join(["a", "b", "c"])   # "a-b-c"  ← 앞의 문자열이 원소 사이에 들어가는 구분자
```

`+`도 문자열끼리는 되지만, 반복문 안에서 `result += char`로 한 글자씩 붙이면 붙일 때마다 새 문자열을 만들어서 길수록 느림

그다음엔 아래처럼 풀었는데 테스트 3번에서 실패했다.

```python
"".join(char.upper() if char=="a" else char.lower() for char in myString)
```

입력에 처음부터 대문자 "A"가 있으면 `char == "a"`가 아니라서 else로 가고, 소문자 "a"로 바뀌어 버림.
예시 입력에 대문자 A가 없어서 예시는 통과했지만, "A는 그대로 둔다"는 경우를 빠뜨렸음. 그래서 `elif char == "A"`를 추가함



### 다른 풀이

```python
def solution(myString):
    return myString.lower().replace("a", "A")
```

- 먼저 전부 소문자로 바꾸면 대문자 "A"도 "a"가 됨 → 그다음 "a"를 전부 "A"로 바꾸면 끝
- 원래 "a"였든 "A"였든 결과는 "A"가 되므로 대문자 A를 따로 처리할 필요가 없음 → 내 풀이에서 빠뜨렸던 경우가 처음부터 생길 수 없음
- 한 글자씩 조건을 따지는 대신, 문자열 전체에 적용되는 메서드(`lower()`, `replace()`)를 순서대로 이어 붙임
- 시간복잡도는 둘 다 O(n)이지만 코드가 한 줄이고 경우 나누기가 없음



### 기록

- 문자열 합치기는 `"".join()`. `append()`는 리스트 전용
- 글자마다 경우를 나누기 전에, 전체를 한 가지로 통일한 뒤(`lower()`) 필요한 것만 바꾸면(`replace()`) 경우의 수가 줄어듦
- 예시만 통과하고 테스트에서 실패하면, 예시에 없는 입력(이번엔 처음부터 대문자 A)을 직접 넣어 볼 것
