### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181851)


### 문제 설명

0번부터 n - 1번까지 n명의 학생 중 3명을 선발하는 전국 대회 선발 고사를 보았습니다. 등수가 높은 3명을 선발해야 하지만, 개인 사정으로 전국 대회에 참여하지 못하는 학생들이 있어 참여가 가능한 학생 중 등수가 높은 3명을 선발하기로 했습니다.

각 학생들의 선발 고사 등수를 담은 정수 배열 rank와 전국 대회 참여 가능 여부가 담긴 boolean 배열 attendance가 매개변수로 주어집니다. 전국 대회에 선발된 학생 번호들을 등수가 높은 순서대로 각각 a, b, c번이라고 할 때 10000 × a + 100 × b + c를 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 3 ≤ rank의 길이 = attendance의 길이 ≤ 100
- rank[i]는 i번 학생의 선발 고사 등수를 의미합니다.
- rank의 원소는 1부터 n까지의 정수로 모두 서로 다릅니다.
- attendance[i]는 i번 학생의 전국 대회 참석 가능 여부를 나타냅니다.
- attendance[i]가 true라면 참석 가능, false면 참석 불가능을 의미합니다.
- attendance의 원소 중 적어도 3개는 true입니다.



### 입출력 예시

| rank | attendance | result |
| --- | --- | --- |
| [3, 7, 2, 5, 4, 6, 1] | [false, true, true, true, true, false, false] | 20403 |
| [1, 2, 3] | [true, true, true] | 102 |
| [6, 1, 5, 2, 3, 4] | [true, false, true, false, false, true] | 50200 |

- 첫 번째: 1등(6번)과 3등(0번)은 참석 불가라 넘어간다. 참석 가능한 학생 중 등수가 높은 순서대로 2등(2번), 4등(4번), 5등(3번)이 선발되어 10000 × 2 + 100 × 4 + 3 = 20403
- 세 번째: 1~3등(1번, 3번, 4번)이 모두 참석 불가라 넘어가고, 4등(5번), 5등(2번), 6등(0번)이 선발되어 10000 × 5 + 100 × 2 + 0 = 50200



### 내 풀이

```python
def solution(rank, attendance):
    ans = []

    while len(ans) != 3:
        num = min(rank)
        i = rank.index(num)
        if attendance[i]:
            ans += [i]
        rank[i] = 101

    return 10000 * ans[0] + 100 * ans[1] + ans[2]
```


### 코드 설명

가장 높은 등수(가장 작은 숫자)부터 하나씩 꺼내면서, 참석 가능한 학생이면 번호를 모으고 3명이 차면 멈춘다.

- `min(rank)`로 남은 학생 중 가장 높은 등수를 찾고, `rank.index(num)`으로 그 학생의 번호(인덱스)를 구한다
- 이미 확인한 학생은 `rank[i] = 101`로 바꿔서 다음 `min`에서 걸리지 않게 한다. 등수가 최대 100이라 101이면 항상 뒤로 밀린다
- 단점
  - **`rank` 원본 리스트를 직접 바꾼다.** 호출한 쪽의 데이터가 망가진다
  - `101`이라는 값이 제한사항(n ≤ 100)에 의존한다. 범위가 바뀌면 틀린다
  - 매번 `min`과 `index`로 전체를 훑어서 O(n × 확인한 학생 수)다. n이 100이라 문제는 없다
- 등수가 모두 다르다는 조건 덕분에 `index`로 학생을 하나로 특정할 수 있다. 같은 등수가 있으면 첫 번째만 찾는다



### 다른 풀이

```python
def solution(rank, attendance):
    order = sorted((r, i) for i, r in enumerate(rank) if attendance[i])
    a, b, c = (i for _, i in order[:3])
    return 10000 * a + 100 * b + c
```

**참석 가능한 학생만 (등수, 번호) 쌍으로 모아서 정렬**하면 앞에서 3명이 곧 선발된 학생이다. 내 풀이처럼 하나씩 찾고 지우는 과정이 필요 없다.

| 단계 | 첫 번째 예시의 결과 |
| --- | --- |
| 참석 가능한 학생의 (등수, 번호) | (7, 1), (2, 2), (5, 3), (4, 4) |
| 정렬 | (2, 2), (4, 4), (5, 3), (7, 1) |
| 앞 3개의 번호 | 2, 4, 3 |
| 계산 | 10000 × 2 + 100 × 4 + 3 = 20403 |

- 튜플은 앞에서부터 비교하니까 **등수 순으로 정렬**된다
- `if attendance[i]`로 참석 불가 학생을 먼저 걸러낸다
- `a, b, c = ...`로 3개를 바로 풀어서 받는다. 개수가 정확히 3개라 가능하다
- 원본 `rank`를 건드리지 않는다
- 시간: 정렬이 O(n log n)

`key`로 정렬 기준을 지정하는 방법도 있다.

```python
def solution(rank, attendance):
    a, b, c = sorted((i for i in range(len(rank)) if attendance[i]), key=lambda i: rank[i])[:3]
    return 10000 * a + 100 * b + c
```

- 참석 가능한 **학생 번호만** 모으고, `key=lambda i: rank[i]`로 "등수 기준으로 정렬"을 지정한다
- 정렬 결과에 번호가 그대로 들어 있어서 쌍에서 번호를 다시 꺼낼 필요가 없다
- 한 줄이 길어서 읽기 어렵다면 `ok = [i for i in range(len(rank)) if attendance[i]]`로 나눠 쓰면 된다
- 세 풀이 모두 랜덤 입력 5만 번으로 결과가 같은지 확인함 (내 풀이는 원본이 바뀌지 않게 복사해서 비교)



### 기록

- **"조건에 맞는 것만 골라서 순위대로 정렬"은 `(기준, 번호)` 튜플 정렬**로 푼다. 튜플은 앞에서부터 비교한다
- 정렬 기준을 따로 주려면 `sorted(대상, key=lambda x: 기준)`
- 길이가 정해진 리스트는 `a, b, c = 리스트`로 바로 풀어서 받을 수 있다. 개수가 다르면 에러
- 값을 "지운 것처럼" 쓰려고 임의의 큰 수(`101`)를 넣는 방식은 입력 원본을 망가뜨리고 범위 제한에 의존한다. 정렬이나 필터로 바꿀 수 있는지 먼저 생각하기
- 조건이 걸린 인덱스와 값이 같이 필요하면 `enumerate()`에 `if` 조건을 붙인다: `for i, r in enumerate(rank) if attendance[i]`
