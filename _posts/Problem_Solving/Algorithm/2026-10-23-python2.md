### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181871)


### 문제 설명

문자열 myString과 pat이 주어집니다. myString에서 pat이 등장하는 횟수를 return 하는 solution 함수를 완성해 주세요.



### 제한사항

- 1 ≤ myString ≤ 1000
- 1 ≤ pat ≤ 10



### 입출력 예시

| myString | pat | result |
| --- | --- | --- |
| "banana" | "ana" | 2 |
| "aaaa" | "aa" | 3 |



### 내 풀이

```python
def solution(myString, pat):
    cnt = 0
    for i in range(len(myString)):
        if myString[i] == pat[0] and myString[i:i+len(pat)] == pat:
            cnt += 1
    return cnt
```


### 코드 설명

처음에는 `myString.count(pat)`으로 풀었는데, 겹쳐서 등장하는 경우를 못 세서 실패했다.

`count()`는 하나를 찾으면 **찾은 부분 다음부터** 다시 찾기 때문

```
"aaaa"에서 "aa" 찾기
count:  [aa]aa → 0~1 찾음 → 2부터 다시 → aa[aa] → 2개
정답:   0~1, 1~2, 2~3 → 3개 (앞의 것과 겹치는 1~2도 세야 함)
```

파이썬 문자열에는 겹치는 것까지 세 주는 함수가 없어서, 시작 위치 i를 한 칸씩 옮기면서 직접 비교했다.

- `myString[i] == pat[0]`: 첫 글자가 다르면 슬라이싱을 건너뜀 (`and`는 앞이 False면 뒤를 계산하지 않음)
- `myString[i:i+len(pat)] == pat`: i부터 pat 길이만큼 잘라서 비교
- 끝부분에서 남은 길이가 pat보다 짧으면 잘린 문자열도 짧아서 자동으로 False → 에러 없음



### 다른 풀이

```python
def solution(myString, pat):
    return sum(myString.startswith(pat, i) for i in range(len(myString) - len(pat) + 1))
```

- `startswith(pat, i)`: i번 인덱스부터 pat으로 시작하는지 True/False로 알려줌. 슬라이싱으로 새 문자열을 만들지 않고 바로 비교함
- `sum()`은 True를 1, False를 0으로 더해서 True 개수가 됨
- `range(len(myString) - len(pat) + 1)`: pat이 들어갈 수 있는 마지막 시작 위치까지만 돎. 뒤쪽 의미 없는 비교를 안 함
- 길이 1000짜리 입력으로 직접 재 보니 내 풀이보다 1.4~2배 빨랐음

정규표현식으로도 셀 수 있다.

```python
import re

def solution(myString, pat):
    return len(re.findall(f'(?={re.escape(pat)})', myString))
```

- `(?=...)`는 lookahead(앞을 내다보기). 글자를 소비하지 않고 "여기서 pat이 시작하는가"만 확인해서 겹치는 것도 다 찾음
- `re.escape(pat)`: pat에 `.`, `*` 같은 특수문자가 있어도 글자 그대로 찾게 함
- 입력에 따라 가장 빠르기도 했지만(랜덤 문자열에서 약 4배) 같은 글자가 반복되는 입력에서는 startswith 풀이보다 느렸음. 코테에서 바로 떠올리기도 어려워서 이런 방법도 있다는 정도로 기억



### 기록

- `count()`는 겹치는 부분 문자열을 세지 않음. 겹치는 것까지 세려면 직접 반복하거나 정규표현식 lookahead
- `s.startswith(pat, i)`: i 위치부터 pat으로 시작하는지 확인. 슬라이싱 비교보다 빠름
- 길이 m짜리를 길이 n 문자열에서 찾을 때 시작 위치는 `0 ~ n-m` → `range(n - m + 1)`
- `sum(조건 for ...)`으로 조건을 만족하는 개수를 셀 수 있음
