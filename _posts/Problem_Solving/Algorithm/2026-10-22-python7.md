### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181861)


### 문제 설명

아무 원소도 들어있지 않은 빈 배열 X가 있습니다. 양의 정수 배열 arr가 매개변수로 주어질 때, arr의 앞에서부터 차례대로 원소를 보면서 원소가 a라면 X의 맨 뒤에 a를 a번 추가하는 일을 반복한 뒤의 배열 X를 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 1 ≤ arr의 길이 ≤ 100
- 1 ≤ arr의 원소 ≤ 100



### 입출력 예시

| arr | result | 
| --- | --- |  
| [5, 1, 4] | [5, 5, 5, 5, 5, 1, 4, 4, 4, 4] |
| [6, 6] | [6, 6, 6, 6, 6, 6, 6, 6, 6, 6, 6, 6] |
| [1] | [1] |



### 내 풀이

```python
def solution(arr):
    answer = []
    for num in arr:
        answer.extend([num] * num)
    return answer
```


### 코드 설명

리스트 뒤에 원소 여러 개를 한 번에 붙이는 `extend()`를 바로 떠올리지 못했다.

`[num] * num`은 num을 num개 담은 리스트를 만듦 → `[5] * 5`는 `[5, 5, 5, 5, 5]`

append()와 extend()의 차이

```python
a = [1, 2]
a.append([3, 4])   # [1, 2, [3, 4]]  ← 리스트가 통째로 원소 하나로 들어감
b = [1, 2]
b.extend([3, 4])   # [1, 2, 3, 4]    ← 원소를 하나씩 풀어서 붙임
```

`answer += [num] * num`도 extend()와 같은 결과



### 다른 풀이

```python
def solution(arr):
    return [num for num in arr for _ in range(num)]
```

- 리스트 컴프리헨션에서 for를 두 번 쓰면 이중 for문과 같음. 앞의 for가 바깥 반복문, 뒤의 for가 안쪽 반복문
- 원소 num마다 안쪽에서 num번 돌면서 num을 하나씩 담음
- 한 줄로 쓸 수 있지만, 길이 100짜리 입력으로 직접 재 보니 내 풀이보다 2배 이상 느렸음
- `[num] * num`과 `extend()`는 파이썬 내부(C)에서 한 번에 처리하고, 컴프리헨션은 원소를 하나씩 담기 때문
- 이 문제는 내 풀이가 더 빠르고 읽기도 쉬움. 이중 for 컴프리헨션은 이런 형태도 있다는 정도로 기억



### 기록

- 원소 하나 붙이기는 `append()`, 여러 개 붙이기는 `extend()` 또는 `+=`
- 같은 값을 여러 개 담은 리스트는 `[값] * 개수`
- 컴프리헨션의 이중 for는 `[x for a in A for x in B]` 순서. 바깥 반복문이 먼저
