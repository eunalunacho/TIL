### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181837)


### 문제 설명

팀의 막내인 철수는 아메리카노와 카페 라테만 판매하는 카페에서 팀원들의 커피를 사려고 합니다. 아메리카노와 카페 라테의 가격은 차가운 것과 뜨거운 것 상관없이 각각 4500, 5000원입니다. 각 팀원에게 마실 메뉴를 적어달라고 하였고, 그 중에서 메뉴만 적은 팀원의 것은 차가운 것으로 통일하고 "아무거나"를 적은 팀원의 것은 차가운 아메리카노로 통일하기로 하였습니다.

각 직원이 적은 메뉴가 문자열 배열 order로 주어질 때, 카페에서 결제하게 될 금액을 return 하는 solution 함수를 작성해주세요. order의 원소는 아래의 것들만 들어오고, 각각의 의미는 다음과 같습니다.

| order의 원소 | 의미 |
| --- | --- |
| "iceamericano", "americanoice" | 차가운 아메리카노 |
| "hotamericano", "americanohot" | 따뜻한 아메리카노 |
| "icecafelatte", "cafelatteice" | 차가운 카페 라테 |
| "hotcafelatte", "cafelattehot" | 따뜻한 카페 라테 |
| "americano" | 아메리카노 |
| "cafelatte" | 카페 라테 |
| "anything" | 아무거나 |



### 제한사항

- 1 ≤ order의 길이 ≤ 1,000



### 입출력 예시

| order | result |
| --- | --- |
| ["cafelatte", "americanoice", "hotcafelatte", "anything"] | 19000 |
| ["americanoice", "americano", "iceamericano"] | 13500 |

- 첫 번째: 차가운 아메리카노 2잔(americanoice, anything), 카페 라테 2잔(cafelatte, hotcafelatte)이라 4500 × 2 + 5000 × 2 = 19000
- 두 번째: 모두 아메리카노라서 4500 × 3 = 13500



### 내 풀이

```python
def solution(order):
    answer = 0
    for menu in order:
        if 'cafelatte' in menu:
            answer += 5000
        else:
            answer += 4500
    return answer
```


### 코드 설명

주문 하나하나가 카페 라테인지 확인해서 가격을 더한다.

- **가격은 "카페 라테인가 아닌가"에만 달려 있다.** 차가운지 따뜻한지는 가격과 무관하다
- `'cafelatte' in menu`는 문자열 안에 부분 문자열이 있는지 확인한다. `"hotcafelatte"`, `"cafelatteice"`, `"cafelatte"` 모두 참이다
- 카페 라테가 아니면 전부 아메리카노(4500)로 계산한다. `"anything"`은 문제에서 아메리카노로 정해 놨으니 `else`로 자연스럽게 처리된다
- 아메리카노 이름(`'americano'`)도 같이 검사하면 `"anything"`을 따로 처리해야 해서 복잡해진다. **한쪽만 확인하고 나머지는 else로 두는 게 간단하다**
- 속도: `in`은 최대 12글자짜리 문자열에서 찾는 거라 사실상 상수 시간이고, 주문 1,000개를 한 번 훑으므로 O(n). 느릴 걱정은 없다



### 다른 풀이

```python
def solution(order):
    return sum(5000 if 'cafelatte' in menu else 4500 for menu in order)
```

- 한 잔씩 가격을 구해 `sum`으로 더한다. `answer` 변수와 `for` / `if` 줄이 필요 없다
- 문제 설명 그대로 "각 주문의 가격을 더한다"로 읽혀서 가독성도 좋다

카페 라테 개수만 세는 방법도 있다.

```python
def solution(order):
    latte = sum('cafelatte' in menu for menu in order)
    return 5000 * latte + 4500 * (len(order) - latte)
```

- `'cafelatte' in menu`는 참이면 1, 거짓이면 0으로 계산되므로 `sum`이 **카페 라테의 개수**가 된다
- 나머지는 `len(order) - latte`로 아메리카노 개수를 구한다
- 이 풀이도 라테 개수를 기준으로 "개수 × 가격"을 계산한다는 점에서 계산 과정이 눈에 보인다

기본 가격에 차이만 더하는 식으로도 쓸 수 있다.

```python
def solution(order):
    return 4500 * len(order) + 500 * sum('cafelatte' in menu for menu in order)
```

- 모두 아메리카노(4500)라고 가정한 뒤, 카페 라테 한 잔당 500원(5000 - 4500)을 더한다
- 짧지만 `500`이라는 숫자의 의미가 한눈에 안 들어와서 첫 번째 `sum` 풀이가 더 읽기 쉽다
- 네 풀이 모두 랜덤 입력 5만 번(길이 1~1,000)에서 결과가 같은지 확인함



### 기록

- **조건 두 가지(아메리카노 / 라테) 중 한쪽만 확인하고 나머지는 `else`로.** 둘 다 검사하면 예외(`"anything"`)를 따로 처리해야 해서 복잡해진다
- `문자열 in 문자열`은 부분 문자열 검사. 대상이 짧으면(12글자) 느리지 않다. 느린 `in`은 **긴 리스트를 반복해서 훑을 때**
- **조건식 결과는 정수처럼 더할 수 있다.** `sum(조건 for x in ...)`은 조건이 참인 개수
- 반복하면서 합계를 `answer += ...`로 쌓는 코드는 `sum(값 for x in ...)`으로 줄일 수 있다
- 가격이 같은 부분(차가운/따뜻한)은 무시하고 **결과에 영향을 주는 기준만 남기기**
