### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181856)


### 문제 설명

이 문제에서 두 정수 배열의 대소관계를 다음과 같이 정의합니다.

- 두 배열의 길이가 다르다면, 배열의 길이가 긴 쪽이 더 큽니다.
- 배열의 길이가 같다면 각 배열에 있는 모든 원소의 합을 비교하여 다르다면 합이 큰 쪽이 더 큽니다.
- 배열의 길이와 모든 원소의 합이 같다면, 두 배열은 같습니다.

두 정수 배열 arr1과 arr2가 주어질 때, 위에서 정의한 배열의 대소관계에 대하여 arr2가 크다면 -1, arr1이 크다면 1, 두 배열이 같다면 0을 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 1 ≤ arr1의 길이 ≤ 100
- 1 ≤ arr2의 길이 ≤ 100
- 1 ≤ arr1의 원소 ≤ 100
- 1 ≤ arr2의 원소 ≤ 100



### 입출력 예시

| arr1 | arr2 | result |
| --- | --- | --- |
| [49, 13] | [70, 11, 2] | -1 |
| [100, 17, 84, 1] | [55, 12, 65, 36] | 1 |
| [1, 2, 3, 4, 5] | [3, 3, 3, 3, 3] | 0 |



### 내 풀이

```python
def solution(arr1, arr2):
    if len(arr1) != len(arr2):
        return 1 if len(arr1) > len(arr2) else -1
    else:
        if sum(arr1) > sum(arr2):
            return 1
        elif sum(arr1) < sum(arr2):
            return -1
        return 0
```


### 코드 설명

문제에 적힌 순서 그대로 길이를 먼저 비교하고, 길이가 같을 때만 합을 비교한다.

- 길이가 다르면 합은 볼 필요가 없으니 바로 return
- 길이가 같으면 합으로 1 / -1 / 0을 나눔
- `sum()`을 `if`와 `elif`에서 각각 두 번씩, 총 4번 호출한다. 결과는 같지만 **같은 계산을 반복**하는 셈이라 변수에 한 번만 담아 두는 게 깔끔하다
- 시간: 길이 100 이하라 O(n)으로 충분



### 다른 풀이

```python
def solution(arr1, arr2):
    a = (len(arr1), sum(arr1))
    b = (len(arr2), sum(arr2))
    return 1 if a > b else -1 if a < b else 0
```

**튜플은 앞에서부터 차례로 비교**한다. 첫 번째 값이 다르면 거기서 결정되고, 같을 때만 두 번째 값을 본다. 문제의 정의(길이 먼저, 같으면 합)와 정확히 같은 규칙이다.

| arr1 | arr2 | a | b | a > b ? |
| --- | --- | --- | --- | --- |
| [49, 13] | [70, 11, 2] | (2, 62) | (3, 83) | 첫 값 2 < 3 → b가 큼 → -1 |
| [100, 17, 84, 1] | [55, 12, 65, 36] | (4, 202) | (4, 168) | 첫 값 같음, 202 > 168 → 1 |
| [1, 2, 3, 4, 5] | [3, 3, 3, 3, 3] | (5, 15) | (5, 15) | 전부 같음 → 0 |

- 비교 대상이 "우선순위가 있는 여러 기준"일 때 튜플로 묶으면 `if`를 중첩하지 않아도 된다
- `sum()`도 배열마다 한 번씩만 호출

한 줄로 줄이는 방법도 있다. 파이썬에서 `True`는 1, `False`는 0이라서 뺄셈으로 -1 / 0 / 1을 만들 수 있다.

```python
def solution(arr1, arr2):
    a = (len(arr1), sum(arr1))
    b = (len(arr2), sum(arr2))
    return (a > b) - (a < b)
```

- `a > b`이면 `1 - 0 = 1`, `a < b`이면 `0 - 1 = -1`, 같으면 `0 - 0 = 0`
- 짧지만 처음 보면 헷갈리는 관용구라서, 읽기 쉬운 쪽은 삼항 연산자 버전
- 두 풀이 모두 랜덤 입력 10만 쌍으로 내 풀이와 결과가 같은지 확인함



### 기록

- **여러 기준으로 순서를 비교할 땐 튜플.** `(기준1, 기준2)` 형태로 묶으면 앞 기준이 같을 때만 다음 기준을 본다
- 같은 값을 여러 번 쓸 거면 변수에 한 번만 계산해서 담기 (`sum()`을 반복 호출하지 않기)
- -1 / 0 / 1 만들기: `(a > b) - (a < b)`. 불리언은 정수처럼 계산됨
- 삼항 연산자는 `A if 조건 else B`이고 이어 붙일 수 있다: `1 if a > b else -1 if a < b else 0`
- 조건 분기가 3가지(큼 / 작음 / 같음)일 때는 `elif`와 마지막 기본 return으로 빠짐없이 나누기
