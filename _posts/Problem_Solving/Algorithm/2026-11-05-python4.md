### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181854)


### 문제 설명

정수 배열 arr과 정수 n이 매개변수로 주어집니다. arr의 길이가 홀수라면 arr의 모든 짝수 인덱스 위치에 n을 더한 배열을, arr의 길이가 짝수라면 arr의 모든 홀수 인덱스 위치에 n을 더한 배열을 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 1 ≤ arr의 길이 ≤ 1,000
- 1 ≤ arr의 원소 ≤ 1,000
- 1 ≤ n ≤ 1,000



### 입출력 예시

| arr | n | result |
| --- | --- | --- |
| [49, 12, 100, 276, 33] | 27 | [76, 12, 127, 276, 60] |
| [444, 555, 666, 777] | 100 | [444, 655, 666, 877] |

- 첫 번째: 길이가 5(홀수)라서 짝수 인덱스 0, 2, 4에 27을 더한다
- 두 번째: 길이가 4(짝수)라서 홀수 인덱스 1, 3에 100을 더한다



### 내 풀이

```python
def solution(arr, n):
    if len(arr)%2==1:
        return [x + n if i%2==0 else x for i, x in enumerate(arr)]
    else:
        return [x + n if i%2==1  else x for i, x in enumerate(arr)]
```


### 코드 설명

길이가 홀수인지 짝수인지로 나누고, 각 경우에 맞는 인덱스에만 n을 더한 새 리스트를 만든다.

- `enumerate(arr)`: 인덱스 `i`와 값 `x`를 같이 꺼낸다
- `x + n if 조건 else x`: 조건에 맞으면 n을 더하고, 아니면 그대로 둔다
- 원본 `arr`을 바꾸지 않고 새 리스트를 반환한다
- 제출한 코드 맨 끝에 `return answer`가 한 줄 더 있었다. `answer`는 정의된 적 없는 변수인데, 앞의 `if`와 `else`에서 이미 return 해서 **실행되지 않아** 에러가 나지 않았을 뿐이다. 쓸모없는 줄이라 지워야 한다
- 두 줄이 거의 똑같고 `i%2==0`과 `i%2==1`만 다르다. 이 차이를 변수로 만들면 한 줄로 합칠 수 있다
- 시간: O(n)



### 다른 풀이

```python
def solution(arr, n):
    r = len(arr) % 2
    return [x + n if i % 2 != r else x for i, x in enumerate(arr)]
```

길이를 2로 나눈 나머지 `r`(홀수면 1, 짝수면 0)과 **인덱스의 나머지가 다른 자리**에 n을 더하면 두 경우가 한꺼번에 처리된다.

| 길이 | r | 더할 인덱스 | i % 2 != r 인 i |
| --- | --- | --- | --- |
| 홀수 | 1 | 짝수 인덱스 (0, 2, 4...) | i % 2 == 0 |
| 짝수 | 0 | 홀수 인덱스 (1, 3, 5...) | i % 2 == 1 |

- 길이가 홀수면 인덱스가 짝수인 자리, 짝수면 인덱스가 홀수인 자리라서 **항상 길이와 반대 홀짝**이다. 이 규칙을 알아채면 분기가 필요 없다
- 결과를 `r`에 이름 붙여 두면 조건이 왜 그렇게 나왔는지도 설명하기 쉽다

시작 인덱스를 계산해서 건너뛰며 더하는 방법도 있다.

```python
def solution(arr, n):
    arr = arr[:]
    for i in range(1 - len(arr) % 2, len(arr), 2):
        arr[i] += n
    return arr
```

- `range(시작, 끝, 2)`로 2칸씩 건너뛰며 더할 자리만 방문한다. 길이가 홀수면 시작이 0, 짝수면 시작이 1
- `arr = arr[:]`로 **복사본을 만들어서** 바꾼다. 이걸 빼면 호출한 쪽의 원본 리스트까지 바뀐다
- 인덱스를 직접 다루는 방식이라 for문이 익숙하면 이해하기 쉽다
- 세 풀이 모두 랜덤 입력 5만 번으로 결과가 같은지 확인함



### 기록

- **if/else 두 갈래의 코드가 거의 같으면 다른 부분을 변수로 빼서 합치기.** 여기서는 `r = len(arr) % 2`
- 인덱스와 값이 같이 필요하면 `enumerate()`. 리스트 컴프리헨션 안에서도 `for i, x in enumerate(arr)`로 쓸 수 있다
- 조건부로 값을 바꿀 땐 `값 if 조건 else 원래값` 형태로 쓴다. `else x`를 빼먹으면 문법 오류
- `range(시작, 끝, 2)`로 홀수나 짝수 인덱스만 골라서 돈다
- 리스트를 직접 바꾸는 코드는 먼저 `arr[:]`나 `arr.copy()`로 복사하기. 안 하면 원본까지 바뀐다
- 도달하지 않는 코드(예: 이미 return 한 뒤의 줄)는 에러가 안 나도 지우기
