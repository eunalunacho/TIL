### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181865)


### 문제 설명

문자열 binomial이 매개변수로 주어집니다. binomial은 "a op b" 형태의 이항식이고 a와 b는 음이 아닌 정수, op는 '+', '-', '*' 중 하나입니다. 주어진 식을 계산한 정수를 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 0 ≤ a, b ≤ 40,000
- 0을 제외하고 a, b는 0으로 시작하지 않습니다.



### 입출력 예시

| binomial | result |
| --- | --- |
| "43 + 12" | 55 |
| "0 - 7777" | -7777 |
| "40000 * 40000" | 1600000000 |



### 내 풀이

```python
def solution(binomial):
    tmp = binomial.split()
    if tmp[1] == '+':
        return int(tmp[0]) + int(tmp[2])
    elif tmp[1] == '-':
        return int(tmp[0]) - int(tmp[2])
    elif tmp[1] == '*':
        return int(tmp[0]) * int(tmp[2])
```


### 코드 설명

`split()`으로 공백 기준으로 나누면 `[a, op, b]` 세 개가 됨 → `"43 + 12".split()`은 `['43', '+', '12']`

나눠진 값은 문자열이라서 `int()`로 바꾼 뒤 연산자에 따라 계산했다.



### 다른 풀이

```python
from operator import add, sub, mul

def solution(binomial):
    a, op, b = binomial.split()
    return {'+': add, '-': sub, '*': mul}[op](int(a), int(b))
```

- `a, op, b = ...`: 리스트를 세 변수에 한 번에 나눠 담음(언패킹). `tmp[0]`, `tmp[2]`보다 무엇인지 읽기 쉬움
- `operator` 모듈의 `add`, `sub`, `mul`은 각각 `+`, `-`, `*`를 함수로 만든 것 → `add(1, 2)`는 3
- 딕셔너리에 연산자 기호와 함수를 짝지어 두고 `op`로 꺼내 바로 호출함. 연산자가 늘어나도 딕셔너리에 한 줄만 추가하면 됨
- 직접 재 보니 속도는 내 풀이가 약간 더 빨랐음(306ns vs 329ns). 속도가 아니라 if문 없이 쓸 수 있다는 정도로 기억

`eval()`을 쓰면 문자열을 파이썬 코드로 실행해서 한 줄로도 풀린다.

```python
def solution(binomial):
    return eval(binomial)
```

- 직접 재 보니 내 풀이보다 약 26배 느렸음(문자열을 코드로 해석하는 과정이 무거움)
- 들어온 문자열을 그대로 실행하기 때문에, 실무에서 외부 입력에 쓰면 아무 코드나 실행될 수 있어 위험함. 코테에서도 권장하지 않음



### 기록

- `a, b, c = 리스트`: 언패킹. 개수가 맞아야 함
- 연산자 분기는 if문 또는 `{기호: operator 함수}` 딕셔너리
- `eval()`은 느리고 위험함. 코테에서도 쓰지 않는 쪽으로
