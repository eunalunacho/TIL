### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181885)


### 문제 설명

오늘 해야 할 일이 담긴 문자열 배열 todo_list와 각각의 일을 지금 마쳤는지를 나타내는 boolean 배열 finished가 매개변수로 주어질 때, todo_list에서 아직 마치지 못한 일들을 순서대로 담은 문자열 배열을 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 1 ≤ todo_list의 길이 1 ≤ 100
- 2 ≤ todo_list의 원소의 길이 ≤ 20
- todo_list의 원소는 영소문자로만 이루어져 있습니다.
- todo_list의 원소는 모두 서로 다릅니다.
- finished[i]는 true 또는 false이고 true는 todo_list[i]를 마쳤음을, false는 아직 마치지 못했음을 나타냅니다.
- 아직 마치지 못한 일이 적어도 하나 있습니다.



### 입출력 예시

| todo_list | finished | result | 
| --- | --- | --- |  
| ["problemsolving", "practiceguitar", "swim", "studygraph"] | [true, false, true, false] | ["practiceguitar", "studygraph"] |



### 내 풀이

```python
def solution(todo_list, finished):
    return [todo for i, todo in enumerate(todo_list) if not (finished[i])]
```


### 코드 설명

처음에 `!(finished[i])`로 썼다가 invalid syntax가 났다. 파이썬에는 `!` 연산자가 없고 부정은 `not`으로 씀.
`!`는 `!=`(같지 않다)에서만 쓰임

| 다른 언어 | 파이썬 |
| --- | --- |
| `!a` | `not a` |
| `a && b` | `a and b` |
| `a \|\| b` | `a or b` |

참/거짓 값도 파이썬에서는 대문자로 시작하는 `True`, `False`로 씀



### 다른 풀이

```python
def solution(todo_list, finished):
    return [todo for todo, done in zip(todo_list, finished) if not done]
```

- zip()은 두 리스트에서 같은 위치의 원소를 하나씩 짝지어 꺼내줌 → ("problemsolving", True), ("practiceguitar", False), ...
- 인덱스 i를 만들어서 finished[i]로 다시 찾아갈 필요 없이, 할 일과 완료 여부를 처음부터 같이 받음
- 시간복잡도는 둘 다 O(n)으로 같지만, 인덱스를 쓰지 않아서 코드가 읽기 쉽고 인덱스 실수가 생길 여지가 없음
- 길이가 같은 두 리스트를 같은 위치끼리 묶어 봐야 할 때는 enumerate + 인덱스 대신 zip()을 먼저 떠올릴 것
