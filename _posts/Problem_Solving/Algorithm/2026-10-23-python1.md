### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181872)


### 문제 설명

문자열 myString과 pat가 주어집니다. myString의 부분 문자열중 pat로 끝나는 가장 긴 부분 문자열을 찾아서 return 하는 solution 함수를 완성해 주세요.



### 제한사항

- 5 ≤ myString ≤ 20
- 1 ≤ pat ≤ 5
- pat은 반드시 myString의 부분 문자열로 주어집니다.
- myString과 pat에 등장하는 알파벳은 대문자와 소문자를 구분합니다.



### 입출력 예시

| myString | pat | result |
| --- | --- | --- |
| "AbCdEFG" | "dE" | "AbCdE" |
| "AAAAaaaa" | "a" | "AAAAaaaa" |



### 내 풀이

```python
def solution(myString, pat):
    idx = myString.rfind(pat)

    return myString[:idx+len(pat)]
```


### 코드 설명

가장 긴 부분 문자열 = 맨 앞부터 pat이 **마지막으로** 나오는 위치까지 자른 문자열

`rfind(pat)`는 오른쪽부터 찾아서 pat이 마지막으로 시작하는 인덱스를 돌려줌

`idx`는 pat의 시작 위치라서 `len(pat)`을 더해야 pat 끝까지 포함됨

```python
"AbCdEFG".rfind("dE")   # 3
"AbCdEFG"[:3 + 2]       # "AbCdE"
```

`find()`를 쓰면 처음 나오는 위치라서 예시 2번이 `"AAAAa"`로 틀림

pat이 겹쳐서 나와도 문제없음 → `"aaa"`, `"aa"`이면 rfind가 1을 돌려줘서 `"aaa"`



### 기록

- 문자열 찾기: `find()`는 앞에서부터 첫 위치, `rfind()`는 뒤에서부터 마지막 위치. 못 찾으면 -1
- `index()`, `rindex()`도 같지만 못 찾으면 에러. 이 문제는 pat이 반드시 있어서 어느 쪽이든 됨
- 찾은 인덱스는 **시작 위치**. 끝까지 자르려면 `+ len(pat)`
- `myString[:myString.rfind(pat)] + pat`처럼 앞부분만 자르고 pat을 붙여도 같은 결과
