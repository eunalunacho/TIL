### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181860)


### 문제 설명

아무 원소도 들어있지 않은 빈 배열 X가 있습니다. 길이가 같은 정수 배열 arr과 boolean 배열 flag가 매개변수로 주어질 때, flag를 차례대로 순회하며 flag[i]가 true라면 X의 뒤에 arr[i]를 arr[i] × 2 번 추가하고, flag[i]가 false라면 X에서 마지막 arr[i]개의 원소를 제거한 뒤 X를 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 1 ≤ arr의 길이 = flag의 길이 ≤ 100
- arr의 모든 원소는 1 이상 9 이하의 정수입니다.
- 현재 X의 길이보다 더 많은 원소를 빼는 입력은 주어지지 않습니다.



### 입출력 예시

| arr | flag | result |
| --- | --- | --- |
| [3, 2, 4, 1, 3] | [true, false, true, false, false] | [3, 3, 3, 3, 4, 4, 4, 4] |



### 내 풀이

```python
def solution(arr, flag):
    X = []
    for i, f in enumerate(flag):
        if f:
            X.extend([arr[i]] * (arr[i] * 2))
        else:
            X = X[:len(X) - arr[i]]

    return X
```


### 코드 설명

처음에는 세 군데를 틀렸다.

```python
if f:
    X.append([arr[i]] * arr[i])       # ① append ② arr[i]번
else:
    X = X[:len(arr) - arr[i]]         # ③ len(arr)
```

1) `append()`를 써서 결과가 `[[3, 3, 3], [4, 4, 4, 4]]`처럼 리스트 안에 리스트가 들어갔다. `append()`는 리스트를 통째로 원소 하나로 넣고, `extend()`는 원소를 하나씩 풀어서 붙인다. 전에 풀었던 [배열의 원소만큼 추가하기]({{ "/pgs/basic/92/" | relative_url }})에서 정리했던 내용인데 또 헷갈렸다.

2) 추가할 개수는 `arr[i]`번이 아니라 `arr[i] × 2`번이다. 문제 조건을 끝까지 안 읽었다.

3) 자르는 기준이 입력 배열 길이 `len(arr)`가 아니라 지금까지 만든 `len(X)`여야 한다. "X에서 마지막 arr[i]개를 제거"이므로 X의 앞에서부터 `len(X) - arr[i]`개만 남긴다.



### 다른 풀이

```python
def solution(arr, flag):
    X = []
    for a, f in zip(arr, flag):
        if f:
            X += [a] * (a * 2)
        else:
            del X[-a:]
    return X
```

- `zip(arr, flag)`: 두 리스트를 같은 위치끼리 묶어서 꺼냄. `arr[i]`를 매번 쓰지 않아도 됨
- `X += 리스트`: `extend()`와 같음
- `del X[-a:]`: 뒤에서 a개를 원본에서 바로 지움. `X = X[:len(X) - a]`는 남길 부분을 **복사해서 새 리스트**를 만들기 때문에 X가 길수록 느림
- a는 1 이상이라 `X[-a:]`가 항상 마지막 a개를 가리킴 (a가 0이면 `X[-0:]`이 `X[0:]`, 즉 전체가 되어 버리니 주의)
- 길이 100짜리 입력으로 직접 재 보니 내 풀이보다 약 1.65배 빨랐음



### 기록

- 리스트에 여러 원소 붙이기는 `extend()` / `+=`. `append()`는 통째로 원소 하나 → 중첩 리스트가 됨
- 뒤에서 n개 지우기: `del X[-n:]` (원본 수정, 복사 없음). n이 0일 수 있으면 `del X[len(X)-n:]`
- 슬라이싱 `X[:k]`는 새 리스트를 만듦(복사). 반복문 안에서 계속 쓰면 느려질 수 있음
- 인덱스가 필요 없고 두 리스트를 같이 돌 때는 `enumerate`보다 `zip`
