### 문제 설명

정수 배열 arr와 2개의 구간이 담긴 배열 intervals가 주어집니다.

intervals는 항상 [[a1, b1], [a2, b2]]의 꼴로 주어지며 각 구간은 닫힌 구간입니다. 닫힌 구간은 양 끝값과 그 사이의 값을 모두 포함하는 구간을 의미합니다.

이때 배열 arr의 첫 번째 구간에 해당하는 배열과 두 번째 구간에 해당하는 배열을 앞뒤로 붙여 새로운 배열을 만들어 return 하는 solution 함수를 완성해 주세요.



### 제한사항

- 1 ≤ arr의 길이 ≤ 100,000
- 1 ≤ arr의 원소 < 100
- 1 ≤ a1 ≤ b1 < arr의 길이
- 1 ≤ a2 ≤ b2 < arr의 길이



### 입출력 예시

| arr | intervals | result | 
| --- | --- | --- |  
| [1, 2, 3, 4, 5] | [[1, 3], [0, 4]] | [2, 3, 4, 1, 2, 3, 4, 5] |



### 내 풀이

```python
def solution(arr, intervals):
    return arr[intervals[0][0]:intervals[0][1]+1] + arr[intervals[1][0]:intervals[1][1]+1]
```


### 코드 설명

일반 리스트에서 +를 하면 뒤에 이어 붙여지고, numpy 배열에서 +를 하면 같은 위치 원소끼리 더한 배열이 리턴된다는 걸 잊고 있었다.

```python
[1, 2, 3] + [4, 5, 6]                       # [1, 2, 3, 4, 5, 6]

import numpy as np
np.array([1, 2, 3]) + np.array([4, 5, 6])   # array([5, 7, 9])
```

이 문제는 두 구간을 앞뒤로 붙이는 거라 리스트끼리 +만 하면 됨
