### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181880)


### 문제 설명

정수가 있을 때, 짝수라면 반으로 나누고, 홀수라면 1을 뺀 뒤 반으로 나누면, 마지막엔 1이 됩니다. 예를 들어 10이 있다면 다음과 같은 과정으로 1이 됩니다.

10 / 2 = 5  
(5 - 1) / 2 = 2  
2 / 2 = 1

위와 같이 3번의 나누기 연산으로 1이 되었습니다.

정수들이 담긴 리스트 num_list가 주어질 때, num_list의 모든 원소를 1로 만들기 위해서 필요한 나누기 연산의 횟수를 return하도록 solution 함수를 완성해주세요.



### 제한사항

- 3 ≤ num_list의 길이 ≤ 15
- 1 ≤ num_list의 원소 ≤ 30



### 입출력 예시

| num_list | result | 
| --- | --- |  
| [12, 4, 15, 1, 14] | 11 |



### 내 풀이

```python
def solution(num_list):
    def calculate(n):
        cnt = 0
        while n != 1:
            n = n//2 if not n%2 else (n-1)//2
            cnt += 1
        return cnt

    return sum([calculate(num) for num in num_list])
```


### 코드 설명

원소 하나를 1로 만드는 횟수를 calculate()로 따로 세고, 원소마다 구한 횟수를 모두 더함.
어제 "조건에 맞게 수열 변환하기 2"에서 정리한 것처럼 원소끼리 서로 영향을 주지 않으니 하나씩 따로 계산하면 됨



### 다른 풀이

**1) 짝수/홀수 구분 없애기**

```python
def solution(num_list):
    def calculate(n):
        cnt = 0
        while n != 1:
            n //= 2
            cnt += 1
        return cnt

    return sum(calculate(num) for num in num_list)
```

- `//`는 소수점 아래를 버리기 때문에 홀수에서 1을 빼고 나누든, 그냥 나누든 결과가 같음 → 15 // 2 = 7, (15 - 1) // 2 = 7
- 그래서 짝수/홀수를 나눌 필요 없이 항상 `n //= 2`만 하면 됨
- `sum([...])` 대신 `sum(...)`으로 대괄호를 빼면 리스트를 따로 만들지 않고 바로 더함

**2) 비트 길이 사용**

```python
def solution(num_list):
    return sum(n.bit_length() - 1 for n in num_list)
```

- 2로 나누기(//2)는 2진수에서 맨 오른쪽 자리를 하나 지우는 것과 같음 → 12 = 1100(2) → 110 → 11 → 1
- 1이 될 때까지 지우는 횟수 = 2진수 자릿수 - 1
- `bit_length()`는 2진수 자릿수를 알려줌 → `(12).bit_length()`는 4라서 12는 3번
- 반복문 없이 원소마다 바로 횟수가 나옴. 원소가 30 이하라 이 문제에서는 속도 차이가 거의 없지만, 값이 아주 클 때 유리함



### 기록

- 홀수 n에 대해 `(n - 1) // 2`와 `n // 2`는 같음. 문제에 "1을 빼고 나눈다"가 나와도 몫(//)으로 계산하면 따로 처리할 필요 없음
- 2로 계속 나누는 횟수를 세는 문제는 2진수 자릿수(`bit_length()`)와 연결해서 생각해 볼 것
