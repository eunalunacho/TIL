### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181890)


### 문제 설명

문자열 리스트 str_list에는 "u", "d", "l", "r" 네 개의 문자열이 여러 개 저장되어 있습니다. str_list에서 "l"과 "r" 중 먼저 나오는 문자열이 "l"이라면 해당 문자열을 기준으로 왼쪽에 있는 문자열들을 순서대로 담은 리스트를, 먼저 나오는 문자열이 "r"이라면 해당 문자열을 기준으로 오른쪽에 있는 문자열들을 순서대로 담은 리스트를 return하도록 solution 함수를 완성해주세요. "l"이나 "r"이 없다면 빈 리스트를 return합니다.



### 제한사항

- 1 ≤ str_list의 길이 ≤ 20
- str_list는 "u", "d", "l", "r" 네 개의 문자열로 이루어져 있습니다.



### 입출력 예시

| str_list | result | 
| --- | --- |  
| ["u", "u", "l", "r"] | ["u", "u"] |
| ["l"] | [] |



### 내 풀이

```python
def solution(str_list):
    if "l" not in str_list and "r" not in str_list:
        return []
    if "l" not in str_list:
        r_idx = str_list.index("r")
        return str_list[r_idx+1:]
    if "r" not in str_list:
        l_idx = str_list.index("l")
        return str_list[:l_idx]
    
    l_idx = str_list.index("l")
    r_idx = str_list.index("r")
    
    if l_idx < r_idx:
        return str_list[:l_idx]
    else:
        return str_list[r_idx+1:]
```


### 코드 설명

"l이나 r이 없다면"은 둘 다 없을 때를 말하는 건데, 처음엔 둘 중 하나만 없어도 빈 리스트를 return해서 실패했다.

그다음엔 하나만 없는 경우를 따로 처리했는데, 둘 다 없는 경우를 빠뜨려서 런타임 에러가 났음.
index()는 찾는 값이 리스트에 없으면 -1을 return하는 게 아니라 ValueError를 냄

```python
["u", "l", "d"].index("r")   # ValueError: 'r' is not in list
```

그래서 index()를 쓰기 전에 in으로 값이 있는지 먼저 확인해야 함



### 다른 풀이

```python
def solution(str_list):
    for i, s in enumerate(str_list):
        if s == "l":
            return str_list[:i]
        if s == "r":
            return str_list[i+1:]
    return []
```

- 앞에서부터 한 칸씩 보다가 l이나 r을 처음 만나는 순간 바로 return
- 처음 만난 문자가 곧 "먼저 나오는 문자"라서 l_idx, r_idx를 따로 구해 비교할 필요가 없음
- 끝까지 l, r을 못 만나고 반복문이 끝나면 둘 다 없는 경우이므로 [] return
- in, index()를 여러 번 쓰면 리스트를 여러 번 훑지만, 이 풀이는 최대 한 번만 훑고 index()를 안 써서 ValueError가 날 일도 없음



### 기록

- 문제에 "처음/먼저 나오는"이 있으면 → 앞에서부터 보다가 조건을 만나는 순간 return (early return)
- 끝까지 다 돌고 나서 비교하는 게 아니라, 찾으면 바로 멈추는 게 핵심
- 잘 맞는 경우: 위치 하나만 알면 답이 정해지고, 원소 하나만 보고 조건 판단이 가능할 때 (`s == "l"`)
- 바꿔 써야 하는 경우
  1) "마지막에 나오는": 뒤에서부터 보다가 멈춤 (`reversed()`, `range(len(arr)-1, -1, -1)`)
  2) 위치가 두 개 이상 필요할 때 (예: 첫 l과 첫 r 사이의 원소): 먼저 만났다고 멈출 수 없으니 인덱스를 각각 구함
  3) 같은 리스트에 여러 번 질문할 때: 매번 훑지 말고 위치를 딕셔너리 등에 한 번 저장해 두고 꺼내 씀
- index()도 내부적으로는 앞에서부터 찾다가 멈춤. 다른 풀이가 나은 이유는 순차 탐색이라서가 아니라, l과 r을 한 번의 탐색에서 동시에 찾기 때문
