### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181882)


### 문제 설명

정수 배열 arr가 주어집니다. arr의 각 원소에 대해 값이 50보다 크거나 같은 짝수라면 2로 나누고, 50보다 작은 홀수라면 2를 곱합니다. 그 결과인 정수 배열을 return 하는 solution 함수를 완성해 주세요.



### 제한사항

- 1 ≤ arr의 길이 ≤ 1,000,000
- 1 ≤ arr의 원소의 값 ≤ 100



### 입출력 예시

| arr | result | 
| --- | --- |  
| [1, 2, 3, 100, 99, 98] | [2, 2, 6, 50, 99, 49] |



### 내 풀이

```python
def solution(arr):
    for i, num in enumerate(arr):
        if num >= 50 and not num%2:
            arr[i] = num/2
        elif num < 50 and num%2:
            arr[i] = num * 2
            
    return arr
```


### 코드 설명

`num%2`는 짝수면 0, 홀수면 1이라서 `not num%2`는 짝수일 때 True, `num%2`는 홀수일 때 True.

`/`는 나누어떨어져도 결과가 항상 실수(float)로 나옴. 그래서 내 풀이는 100이 50이 아니라 50.0이 됨

```python
100 / 2    # 50.0
100 // 2   # 50
```

파이썬에서는 50 == 50.0이 True라서 통과는 했지만, 문제는 정수 배열을 return하라고 했으므로 `//`(몫)를 쓰는 게 맞음



### 다른 풀이

```python
def solution(arr):
    return [n // 2 if n >= 50 and n % 2 == 0
            else n * 2 if n < 50 and n % 2 == 1
            else n
            for n in arr]
```

- `//`를 써서 결과가 정수로 유지됨
- 원본 arr를 직접 바꾸지 않고 새 리스트를 만들어 return → 인덱스 i가 필요 없음
- `not num%2`, `num%2` 대신 `n % 2 == 0`, `n % 2 == 1`로 써서 짝수/홀수 조건이 한눈에 읽힘
- 시간복잡도는 둘 다 O(n). 길이 100만으로 직접 재 보니 두 풀이 모두 0.14초 정도로 속도 차이는 거의 없었음
- 이 문제처럼 3갈래 정도가 조건식으로 쓸 수 있는 한계. 갈래가 더 많아지면 읽기 어려우므로 내 풀이처럼 for문 + if/elif에 `//`만 바꿔 쓰는 게 나음
