### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181836)


### 문제 설명

직사각형 형태의 그림 파일이 있고, 이 그림 파일은 1 × 1 크기의 정사각형 크기의 픽셀로 이루어져 있습니다. 이 그림 파일을 나타낸 문자열 배열 picture과 정수 k가 매개변수로 주어질 때, 이 그림 파일을 가로 세로로 k배 늘린 그림 파일을 나타내도록 문자열 배열을 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- 1 ≤ picture의 길이 ≤ 20
- 1 ≤ picture의 원소의 길이 ≤ 20
- 모든 picture의 원소의 길이는 같습니다.
- picture의 원소는 '.'과 'x'로 이루어져 있습니다.
- 1 ≤ k ≤ 10



### 입출력 예시

| picture | k | result |
| --- | --- | --- |
| [".xx...xx.", "x..x.x..x", "x...x...x", ".x.....x.", "..x...x..", "...x.x...", "....x...."] | 2 | ["..xxxx......xxxx..", "..xxxx......xxxx..", "xx....xx..xx....xx", "xx....xx..xx....xx", ... (총 14줄)] |
| ["x.x", ".x.", "x.x"] | 3 | ["xxx...xxx", "xxx...xxx", "xxx...xxx", "...xxx...", "...xxx...", "...xxx...", "xxx...xxx", "xxx...xxx", "xxx...xxx"] |

두 번째 예시 (`k = 3`)를 그림으로 보면 다음과 같다.

```
x.x          xxx...xxx
.x.    →     xxx...xxx
x.x          xxx...xxx
             ...xxx...
             ...xxx...
             ...xxx...
             xxx...xxx
             xxx...xxx
             xxx...xxx
```



### 내 풀이

```python
def solution(picture, k):
    answer = []

    for line in picture:
        for i in range(k):
            answer.append(''.join(char * k for char in line))

    return answer
```


### 코드 설명

가로로 k배 늘린 줄을 만들고, 그 줄을 세로로 k번 넣는다.

- `char * k`: 글자 하나를 k번 반복. `'x' * 3` → `'xxx'`
- `''.join(char * k for char in line)`: 줄의 각 글자를 k번씩 늘려서 이어 붙인다. `'x.x'`, k = 3이면 `'xxx...xxx'`
- 이 줄을 `answer`에 k번 넣으면 세로로도 k배가 된다

**처음엔 .이 x로 바뀌는 구간을 찾아서 늘리는 방법을 생각했는데, 그럴 필요가 없었다.**

- 연속된 `.`과 `x`의 경계를 찾지 않아도 **글자 하나하나를 각각 k번 반복**하면 같은 결과가 나온다
- 구간 단위로 생각하면 코드가 복잡해지고, 글자 단위로 생각하면 한 줄로 끝난다. 문제를 가장 작은 단위로 쪼개 보기
- 시간: 줄 수 × k × 줄 길이. 최대 20 × 10 × (20 × 10) 정도라 충분하다
- 한 가지 아쉬운 점: **같은 줄을 k번 새로 만든다.** `for i in range(k)` 안에서 늘린 줄을 매번 똑같이 계산한다. 결과는 같으니 한 번만 계산해서 재사용하면 된다



### 다른 풀이

```python
def solution(picture, k):
    answer = []
    for line in picture:
        wide = ''.join(ch * k for ch in line)
        answer += [wide] * k
    return answer
```

- 늘린 줄(`wide`)을 **한 번만** 만들고, `[wide] * k`로 k개를 한꺼번에 붙인다. 같은 계산을 k번 하던 부분이 사라진다
- `answer += 리스트`는 리스트 뒤에 그 원소들을 이어 붙인다 (`extend`와 같다)
- `[wide] * k`는 같은 문자열을 k번 가리키는 리스트다. 문자열은 바뀌지 않는 타입이라 문제 없다. 다만 **리스트의 리스트에서는 위험**하다 (`[[0] * 3] * 2`는 행이 공유되어 한 행을 바꾸면 다른 행도 바뀐다)
- 직접 재 보니 내 풀이는 약 248µs, 이 풀이는 약 24µs로 약 10배 빨랐다 (k = 10, 20줄). 문제 제한에서는 둘 다 한참 빠르지만, k번 반복하던 계산이 사라진 효과다

한 줄로 쓰는 방법도 있다.

```python
def solution(picture, k):
    return [''.join(ch * k for ch in line) for line in picture for _ in range(k)]
```

- 리스트 컴프리헨션의 `for`를 두 번 쓰면 바깥 줄 → 안쪽 반복 순서로 돈다. `for line in picture for _ in range(k)`는 내 풀이의 이중 `for`문과 같다
- `_`는 쓰지 않는 반복 변수
- 짧지만 **줄을 k번 다시 만드는 단점은 그대로**다 (재 보니 약 227µs)

한 번만 만들면서 컴프리헨션으로 쓰려면 이렇게 할 수 있다.

```python
def solution(picture, k):
    return [wide for line in picture for wide in [''.join(ch * k for ch in line)] * k]
```

- `for wide in [늘린 줄] * k`로 늘린 줄을 한 번 만든 뒤 k번 돌린다
- 속도는 위의 반복문 풀이와 같지만 읽기 어렵다. 일반적으로는 반복문 풀이가 더 낫다
- 네 풀이 모두 랜덤 입력 2만 번(줄 수·길이 1~20, k 1~10)에서 결과가 같은지 확인함



### 기록

- **문제를 가장 작은 단위로 쪼개 보기.** 연속된 구간을 찾지 말고 글자 하나하나를 독립적으로 처리하면 단순해진다
- **문자열 `* k`는 반복, 리스트 `* k`도 반복.** `'x' * 3` → `'xxx'`, `[a] * 3` → `[a, a, a]`
- **같은 값을 반복문 안에서 매번 계산하지 말고 밖에서 한 번만 계산해서 재사용.** 위치를 바꾸는 것만으로 속도가 크게 달라진다
- `answer += [값] * k`로 같은 값을 k번 추가할 수 있다
- 리스트의 리스트를 `[[0] * 3] * 2`로 만들면 안쪽 리스트가 공유된다. 문자열 리스트는 바뀌지 않으니 괜찮다
- 이중 `for`문은 컴프리헨션에서 `for A in x for B in y` 순서 그대로 쓴다
