### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181869)


### 문제 설명

단어가 공백 한 개로 구분되어 있는 문자열 my_string이 매개변수로 주어질 때, my_string에 나온 단어를 앞에서부터 순서대로 담은 문자열 배열을 return 하는 solution 함수를 작성해 주세요.



### 제한사항

- my_string은 영소문자와 공백으로만 이루어져 있습니다.
- 1 ≤ my_string의 길이 ≤ 1,000
- my_string의 맨 앞과 맨 뒤에 글자는 공백이 아닙니다.



### 입출력 예시

| my_string | result |
| --- | --- |
| "i love you" | ["i", "love", "you"] |
| "programmers" | ["programmers"] |



### 내 풀이

```python
def solution(my_string):
    return my_string.split(" ")
```


### 코드 설명

`split(구분자)`는 문자열을 구분자 기준으로 잘라서 리스트로 돌려줌

구분자가 없는 문자열은 통째로 원소 하나인 리스트가 됨 → `"programmers".split(" ")`은 `["programmers"]`

이 문제는 공백이 정확히 한 개씩이고 앞뒤에 공백이 없어서 `split(" ")`로 충분하다.



### 기록

`split(" ")`과 `split()`(인자 없음)은 공백이 여러 개이거나 앞뒤에 있을 때 결과가 다르다.

```python
"a  b ".split(" ")   # ['a', '', 'b', '']  ← 공백 하나하나를 구분자로 봐서 빈 문자열이 생김
"a  b ".split()      # ['a', 'b']          ← 연속 공백을 하나로 보고, 앞뒤 공백은 무시
```

- 공백 개수가 일정하지 않을 수 있으면 `split()`을 쓰는 게 안전함
- 탭(`\t`), 줄바꿈(`\n`)도 `split()`은 공백으로 처리함
- 반대로 문자열 리스트를 하나로 합칠 때는 `" ".join(리스트)`
