### 문제 링크

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/389478)

풀이 시간: 약 20분


### 내 풀이

```python
def solution(n, w, num):
    line = num // w
    dest = w if num % w == 0 else num % w
    gap = (w - dest + 1) * 2 - 1

    answer = 1
    now = num
    for i in range(n//w):
        if now + gap <= n:
            answer += 1
            now = now + gap
        else:
            break

        if now + (2 * w - gap) <= n:
            answer += 1
            now = now + (2 * w - gap)
        else:
            break

    return answer
```


### 내 풀이 방식과 정리한 코드

**창고를 쌓지 않고, "같은 열 바로 위 상자의 번호가 지금보다 얼마나 큰가(gap)"만 계산해서 위로 올라가는 방식이다.** (n = 22, w = 6, num = 8)

- `dest`: num이 그 층에서 몇 번째로 놓였는지(1 ~ w). 8은 2번째
- `gap = 2 × (w - dest) + 1`: 바로 위 상자와의 번호 차이. 8의 바로 위는 `8 + 9 = 17`
- 위층은 놓는 방향이 반대라서, 한 층 올라갈 때마다 gap이 `2w - gap`으로 번갈아 바뀐다: `8 → 17 (+9) → 20 (+3) → 29 (+9)`
- 올라간 번호가 n을 넘으면 그 자리에는 상자가 없다는 뜻이라 멈춘다. 맨 위층이 덜 찬 경우도 이 조건으로 처리된다
- 시간 O(n / w), 공간 O(1)

**정리한 코드**: 두 번 반복되던 `if`를 `while` 하나로 합치고, 쓰지 않던 `line`을 지웠다.

```python
def solution(n, w, num):
    q = w if num % w == 0 else num % w
    gap = 2 * (w - q) + 1
    answer = 1
    now = num

    while now + gap <= n:
        now += gap
        answer += 1
        gap = 2 * w - gap

    return answer
```


### 정석 풀이

**문제에 적힌 대로 창고를 2차원 배열로 쌓고, num이 있는 열을 위로 센다.** n ≤ 100이라 이 방식으로 충분하고, 문제 그림과 코드가 그대로 대응해서 가장 틀리기 어렵다. 시간 O(n), 공간 O(n)

```python
def solution(n, w, num):
    rows = (n + w - 1) // w                      # 층 수 (올림)
    grid = [[0] * w for _ in range(rows)]        # 창고. 0은 빈칸

    box = 1
    for r in range(rows):
        cols = range(w) if r % 2 == 0 else range(w - 1, -1, -1)   # 짝수 층: 왼쪽 → 오른쪽, 홀수 층: 오른쪽 → 왼쪽
        for c in cols:
            if box <= n:
                grid[r][c] = box
                box += 1

    for r in range(rows):
        for c in range(w):
            if grid[r][c] == num:
                # num의 열에서, num의 층부터 위로 상자가 있는 칸(0이 아닌 칸)을 센다
                return sum(1 for rr in range(r, rows) if grid[rr][c] != 0)
```

n = 22, w = 6이면 창고는 아래와 같고, 8은 `grid[1][4]`다. 열 4를 `r = 1`부터 위로 읽으면 8, 17, 20이라 3개다. 빈칸(0)은 세지 않아서 맨 위층이 덜 찬 경우도 따로 처리하지 않아도 된다.

```
r = 0   [ 1,  2,  3,  4,  5,  6]
r = 1   [12, 11, 10,  9,  8,  7]
r = 2   [13, 14, 15, 16, 17, 18]
r = 3   [ 0,  0, 22, 21, 20, 19]
```


### 최적화 풀이

**반복문 없이 O(1)로 계산한다.** num의 층부터 맨 위층 바로 아래층까지는 꽉 찬 층이라 같은 열에 층마다 상자가 하나씩 있다. 그래서 그 층 수를 세고, 덜 찰 수 있는 맨 위층에만 같은 열의 상자가 있는지 확인한다.

```python
def solution(n, w, num):
    floor, order = divmod(num - 1, w)                  # num이 놓인 층, 그 층에서 놓인 순서 (둘 다 0부터)
    col = order if floor % 2 == 0 else w - 1 - order   # num이 있는 열 (왼쪽부터 0부터)

    top = (n - 1) // w                                 # 맨 위층 (0부터)
    cnt = n - top * w                                  # 맨 위층에 놓인 상자 수
    if top % 2 == 0:
        has_top = col < cnt                            # 왼쪽 → 오른쪽: 왼쪽 cnt칸에 상자가 있다
    else:
        has_top = col >= w - cnt                       # 오른쪽 → 왼쪽: 오른쪽 cnt칸에 상자가 있다

    return (top - floor) + int(has_top)
```

n = 22, w = 6, num = 8:

- `divmod(7, 6) = (1, 1)`이라 `floor = 1`, `order = 1`. 홀수 층이라 열을 뒤집어 `col = 6 - 1 - 1 = 4`
- `top = 21 // 6 = 3`, `cnt = 22 - 18 = 4`. 맨 위층은 오른쪽부터 놓아서 상자가 열 `w - cnt = 2` ~ 5에 있다
- `col = 4`는 `4 >= 2`라서 맨 위층에 있다 (`has_top = True`)
- 답은 `(3 - 1) + 1 = 3` (8, 17, 20)


### 내가 놓친 것

- **`divmod(a, b)` = `(a // b, a % b)`.** 몫과 나머지를 한 번에 구한다. 번호에서 층과 그 층의 순서를 구할 때 `divmod(num - 1, w)`로 쓴다
- **번호를 0부터 세려면 `num - 1`을 먼저 나눈다.** `num % w`는 w의 배수(6, 12, ...)에서 0이 되어서 `dest = w if ... else ...`로 따로 처리해야 했다. `(num - 1)`을 쓰면 이 분기가 필요 없다
- **지그재그 배치는 홀수 층에서 열을 뒤집는다:** `col = w - 1 - 순서`
- **층 수 올림은 `(n + w - 1) // w`.**
- **꽉 찬 부분은 개수로 세고, 덜 찰 수 있는 맨 위층만 따로 확인한다.**
- **식이 맞게 나와도 의미를 주석으로 남긴다.** `(w - dest + 1) * 2 - 1`, `2 * w - gap`은 식만 봐서는 의미를 알기 어렵다. 쓰지 않는 변수(`line`)와 반복되는 `if` 블록도 정리한다
- 테스트 그룹에서 점수가 가장 큰 그룹(#3, 70%)은 **맨 위층이 덜 찬 경우**가 핵심이다
